## 核心算法规则

### 语境分类（7 类）

| 语境 | 匹配规则 |
|---|---|
| 开发 | IDE（Code, Codex, VS, Rider, Terminal, PowerShell, cmd, Git, dotnet） |
| 研究 | 浏览器技术文档 / 搜索 / GitHub / StackOverflow / 未命中其他分类的浏览器标题 |
| 沟通 | WeChat, Teams, Slack, Outlook, 邮件, 飞书 |
| 娱乐 | bilibili, 小红书, 微博, 直播吧, 视频/直播/游戏 等浏览器标题 |
| 系统 | Settings, Task Manager（注：Explorer 已从 Agent 采集端默认排除，不再参与分析） |
| 效率 | Word, Excel, Notion, Obsidian, Zotero, Typora |
| 其他 | 未命中上述所有规则 |

### 工作块检测

```
Active 样本按时间排序
相邻 Active 样本间隔 ≤ 5 分钟 → 同一 block
block 持续时间 ≥ 25 分钟 → 候选工作块
展示前 4 个（按 duration 降序）
```

### 有效专注段判断

```
block ≥ 25 分钟
meaningful context switch count ≤ 3
主语境占比 ≥ 70%
```

### 中断源排名

```
统计所有"工作语境 → 非工作语境"的 App 跳转
按次数降序，取前 6
工作语境 = { 开发, 效率, 研究 }
```

### 语境切换排名

```
统计所有有意义语境切换的 (From → To) pair
按次数降序，取前 8
Each pair 附带占比 (0.0–1.0)
```

## 文案原则

- 禁止："你效率很差"、"你不专注"、"你浪费时间"
- 推荐："你今天有 2 段较长开发块，但微信和娱乐内容插入较多。可以尝试一个 45 分钟 Code-only 块。"
