## 实现的行为

PruneData：
  Running → Maintenance → Running
  Paused  → Maintenance → Paused

ClearHistory：
  Running → Maintenance → Paused
  Paused  → Maintenance → Paused

失败：
  任何状态 → Maintenance → try/finally 保证退出，写 CommandFailed，安全文案不泄露路径

Maintenance 期间：
  TickAsync 只写心跳，不捕获 foreground sample
  PruneData / ClearHistory 重复触发被拒绝（AlreadyInMaintenance）
  Start / Pause / Resume / Stop — MainWindowViewModel can-execute 禁用，Dashboard 显示维护提示
  Reload — SettingsViewModel can-execute 禁用，文案 "Agent is performing maintenance"

不做：
  SQLite DELETE、JSONL 删除、VACUUM、Settings Data Management UI、ClearHistory 二次确认
