## ClearHistory 数据层行为

SQLite 清空（事务）：
  DELETE FROM foreground_samples
  DELETE FROM app_sessions
  DELETE FROM agent_events
  BEGIN TRANSACTION → 三条 DELETE → COMMIT；任一失败 → ROLLBACK
  缺表时安全返回 0

JSONL 删除：
  目标文件：agent_events_YYYYMMDD.jsonl / foreground_samples_YYYYMMDD.jsonl
  删除条件：fileDateLocal < 今天（不删除当天文件）
  HistoryCleared 在清空后追加到当天 agent_events_YYYYMMDD.jsonl

状态恢复：
  Running → ClearHistory → Paused
  Paused  → ClearHistory → Paused
