3. 按钮状态联动

ClearHistoryCommand 和 PruneDataCommand 的 CanExecute 需要随 Agent 状态变化正确禁用/启用。

方案：两个命令的 CanExecute 都使用 `CanExecuteDataCleanup`（而非 CanReloadAgentConfig）。

在 UpdateAgentStatusAsync 方法中（约 L1036-1059），与 CanReloadAgentConfig 设置并排：
```
CanExecuteDataCleanup = status.IsRunning
    && (status.ActualState == AgentActualState.Running
        || status.ActualState == AgentActualState.Paused);
```
注意 Maintenance 不在允许列表中，所以 Maintenance 期间按钮禁用。
catch 块中同时将 CanExecuteDataCleanup 设为 false。

同时将 ClearHistoryCommand 的 CanExecute 表达式从依赖 CanReloadAgentConfig 改为依赖 CanExecuteDataCleanup：
```
ClearHistoryCommand = new AsyncRelayCommand(ClearHistoryAsync, () => !IsLoading && !IsSaving && CanExecuteDataCleanup);
```

这样 Reload Config 按钮和数据管理按钮的启用条件独立，语义更清晰。

CanReloadAgentConfig setter 中的 NotifyCanExecuteChanged 不再需要通知 ClearHistoryCommand 或 PruneDataCommand（因为它们不再依赖 CanReloadAgentConfig）。
