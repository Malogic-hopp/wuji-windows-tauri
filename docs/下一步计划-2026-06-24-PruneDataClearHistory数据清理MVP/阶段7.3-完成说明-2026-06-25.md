## 实现的行为

PruneData 成功流程：
  CommandDetected → CommandAccepted → Maintenance → PruneDataAsync(_options.RetentionDays)
  → DataPruned 事件 → CommandCompleted → 恢复原状态

PruneData 失败流程：
  DataMaintenanceService 返回 Success=false 或抛异常
  → CommandFailed + errorCode + 安全文案
  → finally 退出 Maintenance，恢复原状态

状态恢复：
  Running → PruneData → Running
  Paused  → PruneData → Paused

错误处理：
  result.ErrorCode 传递到 CommandFailed
  result.SafeMessage 脱敏，不含路径
  DiagnosticMessageSanitizer 处理异常文本
  JSONL partial failure 视为整体失败

DataPruned payload：
  retentionDays / cutoffUtc / cutoffLocalDate / foregroundSamplesDeleted
  / sessionsDeleted / agentEventsDeleted / jsonlFilesDeleted
  / jsonlDeleteErrorCount / actualState
  不包含窗口标题、路径、SQL、异常原文
