## 实现的行为

SQLite 删除（事务）：
  DELETE FROM foreground_samples WHERE sample_time_utc < cutoffUtc
  DELETE FROM app_sessions WHERE ended_at_utc IS NOT NULL AND ended_at_utc < cutoffUtc
  DELETE FROM agent_events WHERE event_time_utc < cutoffUtc
  BEGIN TRANSACTION → 三条 DELETE → COMMIT；任一失败 → ROLLBACK
  缺表时安全返回 0

JSONL 删除：
  目标文件：agent_events_YYYYMMDD.jsonl / foreground_samples_YYYYMMDD.jsonl
  文件日期严格解析 8 位数字 + ".jsonl" 后缀
  删除条件：fileDateLocal < cutoffLocalDate
  当前日期和 cutoffLocalDate 当天文件保留
  非目标文件（.log、.jsonl.bak、random_*.jsonl）不删除
  配置文件、runtime 文件、数据库文件本体、WAL/SHM 不删除
  删除失败时记入 jsonlDeleteErrorCount，不暴露路径

cutoff 口径：
  SQLite：cutoffUtc = referenceTimeUtc - retentionDays
  JSONL：cutoffLocalDate = referenceLocalDate - retentionDays
