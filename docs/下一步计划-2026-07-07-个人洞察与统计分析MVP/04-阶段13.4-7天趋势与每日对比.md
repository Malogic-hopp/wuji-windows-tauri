# 阶段 13.4：7 天趋势与每日对比

## 阶段目标

基于 DailyStatsService 扩展最近 7 天趋势，让用户知道今天相对最近状态是上升、下降还是异常。

一句话目标：

```text
让 WUJI 从“今天统计”扩展到“最近变化”。
```

## 实施范围

建议新增：

```text
WeeklyTrendService 或 DailyStatsService.GetRangeAsync
DailyTrendPoint
TrendComparison
```

优先趋势：

```text
过去 7 天活跃时间
过去 7 天最长专注段
过去 7 天上下文切换次数
过去 7 天 Top App 变化
今日 vs 7 天平均
```

## 行为要求

```text
1. 7 天趋势基于本地日期。
2. 缺失日期要补 0 点，不要让图表/列表错位。
3. 今日未结束时，比较文案要避免误导，可使用“截至目前”。
4. 趋势计算仍是只读，不写 SQLite。
5. Dashboard 展示应轻量，不做复杂图表库。
6. 可先用简洁列表 / 小型条形展示，不引入大型图表依赖。
7. 查询失败时保留旧趋势数据。
8. status polling 不触发 7 天趋势刷新。
9. 时间格式和单位与阶段 13.2 保持一致。
10. 不引入周报文档生成。
```

## 验收标准

```text
1. 能返回最近 7 天 DailyTrendPoint。
2. 缺失日期补齐。
3. Dashboard 可展示 7 天活跃趋势。
4. Dashboard 可展示今日 vs 7 天平均的简单比较。
5. 查询失败不清空旧趋势。
6. build/test 通过，0 warnings / 0 errors。
```

## 建议测试

```text
WeeklyTrend_ReturnsSevenLocalDays
WeeklyTrend_FillsMissingDaysWithZero
WeeklyTrend_ComputesAverageExcludingTodayOrIncludingByDocumentedRule
WeeklyTrend_ComparesTodayAgainstAverage
Dashboard_ShowsSevenDayTrend
Dashboard_StatusPollingDoesNotReloadTrend
```

## 不做什么

```text
不做月报
不做年报
不做导出
不做复杂交互图表
不做云同步
不做安装包
```
