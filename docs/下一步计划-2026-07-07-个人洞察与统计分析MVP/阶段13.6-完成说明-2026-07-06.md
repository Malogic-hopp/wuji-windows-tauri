## 实现行为

### 1. 统计数据更新时间

Dashboard 的 Summary Text 卡片底部显示最新刷新时间：

```
┌─ Summary ──────────────────────────────────────┐
│ 今日活跃 2h 30m，主要在 Code、Browser，42 次采样… │
│ 更新于 2026-07-06 14:30:00                      │
└─────────────────────────────────────────────────┘
```

- 每次 `ApplySummary` 成功时写入本地当前时间
- 加载失败时保留上次时间戳不清空
- 首次加载前显示空字符串

### 2. EvidenceText 隐私安全

`InsightSuggestionEngine` 的所有 EvidenceText 仅使用聚合数据（计数、时长、App 名称），不使用原始窗口标题。已验证不包含：
- `C:\` 路径
- `Users` 敏感目录名
- `Secret` / `password` 等关键词

### 3. 洞察依据可读性

已在阶段 13.5 完成——每条建议卡片展示 Title、Message、EvidenceText、ActionText 四个层级。
