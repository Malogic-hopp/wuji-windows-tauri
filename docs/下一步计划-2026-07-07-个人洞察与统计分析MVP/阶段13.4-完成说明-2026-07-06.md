## 7 天日期范围规则

```text
区间: [today - 6 days, today]，共 7 个本地日期
排序: 最早在最前（Day 0），今天在最后（Day 6）
```

使用 `DateOnly.FromDateTime(DateTime.Now)` 获取今天，`today.AddDays(i - 6)` 倒推前 6 天。

## 历史日期处理

`DailyStatsService.GetSummaryForDateAsync(date)` 的关键差异：

| 日期类型 | effectiveNow | 说明 |
|---|---|---|
| 今天 | `DateTime.UtcNow` | 未结束的 session 延伸到当前时间 |
| 历史日期 | `rangeEndUtc`（当天结束 UTC） | 未结束的 session 裁剪到当天边界 |

避免历史日期的 open session 被错误地拉伸到今天。

## 平均值计算规则

- 7 天平均值：所有 7 天（含今天）的简单算术平均
- 比较文案基于今天值 / 平均值比率：
  - `>= 1.3`：显著高于
  - `>= 1.1`：略高于
  - `<= 0.7`：显著低于
  - `<= 0.9`：略低于
  - 其他：接近

## 缺失日期处理

无数据的日期（数据库无记录或查询失败）返回全零 `DailyTrendPoint`。7 天窗口始终固定为 7 个点，不会因为缺失而移位。

## 并行查询策略

7 天摘要通过 `Task.WhenAll` 并行查询，每日期独立打开只读 SQLite 连接。单日查询失败不影响其他日期（捕获为全零点）。

## Dashboard 展示变化

### 新增 7-Day Trend 区域

位于统计卡片下方、Top Apps 上方：

```
┌─ 7-Day Trend ─────────────────────────────────────┐
│  周一    周二    周三    周四    周五    周六    今天  │
│  0m      0m      0m      0m      0m      30m     2h 0m  │
│                                                    │
│  今日活跃时间显著高于近 7 天平均                      │
│  今日最长专注接近近 7 天平均                          │
│  今日切换显著少于近 7 天平均，较为专注                │
└────────────────────────────────────────────────────┘
```

- 每天显示星期简称（今天显示"今天"）+ 格式化活跃时长
- 3 行对比文案：活跃时间趋势、专注趋势、切换趋势
- 切换对比使用反向阈值（少=好）
