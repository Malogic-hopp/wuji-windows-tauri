## Focus Session 定义

一个专注段满足以下全部条件：

| 条件 | 阈值 | 说明 |
|---|---|---|
| 所有样本为 Active | `ActivityState == "Active"` | Idle / Unknown 样本打断专注段 |
| 连续样本间隔 ≤ MaxGap | `3 分钟` | 超过则开启新段 |
| 段内切换次数 ≤ MaxSwitches | `3 次` | 超过标记为碎片化 |
| 段持续时长 ≥ MinFocus | `10 分钟` | 不足不统计为专注段 |

## Context Switch 定义

连续两个 Active 状态样本的 `process_name` 或 `window_title` 发生变化，即计一次切换。跨 gap 的样本对也计入（切换统计独立于专注段分割）。

## 碎片化时间定义

段内切换次数超过 `MaxSwitchesPerFocusBlock`（3 次）的 segment，其全部时长计入碎片化时间。

## 阈值列表

| 常量 | 值 | 说明 |
|---|---|---|
| `DefaultMinimumFocusMinutes` | 10 | 最小专注段时长 |
| `DefaultMaxGapMinutes` | 3 | 最大允许间隔 |
| `DefaultMaxSwitchesPerFocusBlock` | 3 | 专注段内最大切换次数 |

阈值在 `FocusMetricsCalculator` 中以常量定义，可通过参数覆盖。当前未暴露到 Settings UI。

### 一句话摘要增强

摘要现在包含专注质量信息：
- 有专注段时：`今日活跃 2h 30m，主要在 Code、Browser，42 次采样，最长专注 15m`
- 高碎片化时：`…最长专注 15m（较分散）`
- 无专注段时：`…暂未检测到完整专注段`
- 切换频繁时：`…切换较为频繁`

## 已知限制

1. **专注段基于 sample 粒度**：专注段时长 = 第一个和最后一个 active sample 的时间差，不是实际活跃时长。采样间隔越短越精确。
2. **碎片化判断简单**：仅基于段内切换次数比较阈值，不使用滑动窗口或统计学方法。
3. **不区分标题变化类型**：窗口标题微小的动态变化（如时钟更新）也会被计为切换。
4. **阈值未暴露到 UI**：当前为代码常量，未来可考虑加入 Settings。
5. **跨日边界**：仅分析当日 samples，不分析跨日专注段。
