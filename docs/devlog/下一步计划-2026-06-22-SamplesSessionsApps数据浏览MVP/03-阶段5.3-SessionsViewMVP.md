# 阶段 5.3：SessionsView MVP

## 阶段目标

让用户能看到会话边界、时长分布和关闭原因。

这一页用于验证：

```text
session 合并是否正确
应用切换是否生成 ProcessChanged
Pause 是否关闭 session
Stop 是否关闭 session
open session 展示是否清楚
```

## 前置条件

阶段 5.1 已完成：

```text
SessionQueryService.GetRecentSessionsAsync(limit = 200)
SessionQueryService.GetSessionsForLocalDayAsync(localDate, limit = 200)
```

## 页面内容

第一版展示：

```text
Started local time
Ended local time
Process
Display name
Total duration
Active duration
Idle duration
Unknown duration
Close reason
Session id
```

`close_reason` 是这一页的核心字段，建议作为明显列展示，不要只放详情里。

open session 的 ended time 显示：

```text
正在进行
```

或等价文案，不显示空白。

## 基础交互

第一版支持：

```text
Refresh
最近 200 条
范围切换：Today / Last 24 Hours / Recent
CloseReason 筛选：All / Open / ProcessChanged / Paused / Stopped / Other
```

## 范围口径

Today：

```text
与本地当天时间区间有重叠的 session
```

不要简单按：

```text
started_at_utc 日期 = 今天
```

Last 24 Hours：

```text
与当前时间往前 24 小时时间区间有重叠的 session
```

Recent：

```text
最近 200 条，按 started_at_utc DESC, id DESC
```

## CloseReason 口径

第一版只做：

```text
All
Open
ProcessChanged
Paused
Stopped
Other
```

暂不预设尚未确认真实写入的 close_reason：

```text
AgentStarted
PrivacyExcluded
Sleep
ScreenLock
AgentCrashRecovered
```

这些需要先确认真实链路会写入 `app_sessions.close_reason`，再加入独立筛选。

## 验收标准

- SessionsView 能显示最近 session
- Today 按本地日重叠查询
- Last 24 Hours 范围正确
- 时长格式可读
- close_reason 可见
- open session 的 ended time 不显示空白
- 空表显示友好空态
- Pause 后可看到 `close_reason = Paused`
- Stop 后可看到 `close_reason = Stopped`
- 切换应用后可看到 `close_reason = ProcessChanged`
