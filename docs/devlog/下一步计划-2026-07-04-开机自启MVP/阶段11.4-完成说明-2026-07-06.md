## App.xaml.cs 启动流程调整说明

```
手动启动 (--from-autostart 缺失 或 仅 --start-hidden):
    创建 MainWindow / ViewModel / TrayService
    window.Show()  →  Loaded → InitializeAsync (status polling + timers)
    主窗口可见

自启启动 (同时 --from-autostart + --start-hidden):
    创建 MainWindow / ViewModel / TrayService
    跳过 window.Show()
    显式调用 viewModel.InitializeAsync() (启动 status polling + timers)
    托盘图标可见
    主窗口不弹出
```

## WindowStartupPolicy 设计说明

| 输入 | ShouldShowMainWindowOnLaunch | ShouldStartHidden |
|---|---|---|
| 无参数 | true | false |
| `--start-hidden` | true | false |
| `--from-autostart` | true | false |
| `--from-autostart --start-hidden` | **false** | **true** |

纯逻辑，不依赖 Window / Dispatcher / NotifyIcon，完全可单元测试。

## 手动启动与自启隐藏的区分

- 手动启动：`window.Show()` 触发 WPF `Loaded` 事件 → `InitializeAsync` 启动 polling → 窗口可见
- 自启隐藏：跳过 `window.Show()`，直接调用 `InitializeAsync` 启动 polling → 窗口不可见 → 托盘图标可见 → 用户通过托盘 Show 恢复

关键区分点：
- 不通过 `Window.Closing` / `CloseToTray` 模拟隐藏（启动策略直接决定是否 Show）
- `Application.Current.MainWindow = window` 在两种模式下都设置（App.xaml.cs 中 `MainWindow = window`）
- 托盘 Show 恢复的是同一个 MainWindow（复用阶段 10 的 `Show() + WindowState=Normal + Activate()`）

## Agent 自启行为

本阶段不改变 Agent 启动逻辑。`AutoStartAgentWhenAppStarts` 由 `MainWindowViewModel.InitializeAsync` 在 AppSettings 加载后按现有语义处理：
- `true`：启动 Agent
- `false`：不启动 Agent

该行为在手动启动和自启隐藏下一致（都走 `InitializeAsync`）。
