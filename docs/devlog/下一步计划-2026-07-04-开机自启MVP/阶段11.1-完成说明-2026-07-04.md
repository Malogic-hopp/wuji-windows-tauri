## AppSettings 变更说明

```csharp
public bool StartAppOnWindowsLogin { get; set; }  // 默认 false
```

- 旧 `app-settings.json` 缺少此字段时，`System.Text.Json` 反序列化自动置为 `default(bool)` = `false`
- 新增保存会稳定 round-trip 该字段
- 与 `AutoStartAgentWhenAppStarts` 严格独立：前者控制"Windows 登录是否启动 App"，后者控制"App 启动后是否启动 Agent"

## StartupLaunchOptions 设计说明

| 参数组合 | Mode | FromAutostart | StartHidden |
|---|---|---|---|
| (无参数) | Manual | false | false |
| `--from-autostart` | AutoStart | true | false |
| `--start-hidden` | Manual | false | true |
| `--from-autostart --start-hidden` | AutoStart | true | true |

参数解析规则：
- 大小写不敏感：`--FROM-AUTOSTART` = `--from-autostart`
- 未知参数安全忽略，不抛异常
- `RawArgs` 保留原始命令行参数（仅用于测试/内部调试，不暴露到 UI）

## App.xaml.cs 解析衔接说明

- 在 `OnStartup` 开头调用 `StartupLaunchOptions.Parse(e.Args)`，存储到 `_startupLaunchOptions`
- 本阶段**仅解析，不改变任何启动行为**：手动启动仍显示主窗口，自启参数启动也仍显示主窗口
- 未将 `StartupLaunchOptions` 传入 `TrayService` 或 `MainWindowViewModel`
- 阶段 11.4 才会根据 `LaunchMode` 决定是否隐藏窗口

## SettingsViewModel 预支持说明

- `LoadAsync`：从 `app-settings.json` 读取 `StartAppOnWindowsLogin`，应用到编辑器
- `SaveAppSettingsAsync`：`TryBuildAppSettings` 将 `StartAppOnWindowsLogin` 写回 `AppSettings`
- 保存时不调用任何注册表操作，不访问 HKCU Run Key
- Settings UI 本阶段不新增开关控件（阶段 11.3 做）
