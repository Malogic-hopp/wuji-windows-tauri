# 阶段 11.4：登录自启启动到托盘

## 阶段目标

让 App 通过自启参数启动时默认隐藏到托盘，并继续运行阶段 10 的托盘和状态刷新链路。

## 背景

开机自启的用户体验应当是“登录后 WUJI 进入托盘后台常驻”，而不是弹出主窗口打扰用户。自启隐藏应由启动策略决定，不能通过模拟关闭窗口来绕阶段 10 的 CloseToTray 逻辑。

## 行为要求

启动参数：

```text
--from-autostart
--start-hidden
```

手动启动：

```text
没有 --from-autostart:
    window.Show()
    保持现有行为。
```

自启启动：

```text
有 --from-autostart 和 --start-hidden:
    创建 MainWindow / ViewModel / TrayService。
    启动 status polling。
    直接不调用 window.Show()，或通过启动策略确保无闪烁隐藏。
    托盘图标可见。
    托盘 Show Main Window 可恢复窗口。
    不通过 Window.Closing / CloseToTray 模拟隐藏。
```

Agent 自启：

```text
如果 AutoStartAgentWhenAppStarts=false:
    不自动启动 Agent。

如果 AutoStartAgentWhenAppStarts=true:
    按既有 App 启动流程启动 Agent。
```

安全要求：

```text
自启启动失败不写敏感路径到 UI。
自启模式不弹出阻塞式错误对话框。
自启模式启动期错误写入安全状态文本 / Diagnostics / 日志。
自启模式不改变 Exit App 语义。
```

## 建议新增或调整

如果直接测试 `App.xaml.cs` 困难，优先抽出可测试协调器：

```text
src/QuantifiedSelf.Windows.App/Services/AppStartupCoordinator.cs
src/QuantifiedSelf.Windows.App/Services/WindowStartupPolicy.cs
```

阶段 11.4 优先对 `AppStartupCoordinator` / `WindowStartupPolicy` 做纯逻辑测试；不要为了自动化覆盖真实 WPF startup 而引入脆弱 UI 测试。真实托盘启动到隐藏状态留给手动验收覆盖。

## 建议测试

```text
AppStartup_ManualLaunchShowsMainWindow
AppStartup_AutostartHiddenDoesNotShowMainWindow
AppStartup_AutostartHiddenCreatesTray
AppStartup_AutostartHiddenStartsStatusPolling
AppStartup_AutostartRespectsAutoStartAgentFalse
AppStartup_AutostartRespectsAutoStartAgentTrue
TrayService_ShowRestoresAutostartHiddenWindow
WindowStartupPolicy_DoesNotUseCloseToTrayForAutostartHidden
```

## 验收标准

```text
build 0 warning / 0 error
test 全部通过
手动启动仍显示主窗口
自启参数启动时默认隐藏到托盘
自启参数启动后 status polling 正常
托盘 Show 可恢复主窗口
AutoStartAgentWhenAppStarts=false 时不启动 Agent
AutoStartAgentWhenAppStarts=true 时启动 Agent
CloseToTray / MinimizeToTray / Exit App 不回归
AutoStartHidden 模式不弹阻塞式 MessageBox
```

## 不做什么

```text
不做安装包启动入口
不做 Windows Service
不做复杂 single-instance 激活
不改变托盘命令
不改变 Agent 控制链路
```
