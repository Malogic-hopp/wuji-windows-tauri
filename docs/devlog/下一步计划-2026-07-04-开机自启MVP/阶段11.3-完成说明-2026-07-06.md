## 保存同步注册状态说明

| 场景 | 行为 |
|---|---|
| 开启开关（false→true） | 先 `RegisterAsync()`，成功再保存 AppSettings |
| 关闭开关（true→false） | 先 `UnregisterAsync()`，成功再保存 AppSettings |
| unchanged true + OS Mismatch | 自动 `RegisterAsync()` 修复 |
| 只改 AutoStartAgentWhenAppStarts | 不调用 register/unregister |
| 注册/取消注册失败 | 显示安全错误，不保存，保留 IsDirty，允许重试 |

## 注册状态展示说明

`StartupRegistrationStatusText` 由 `RefreshStartupRegistrationStatusAsync()` 驱动，在 Load 和 Save 后自动更新，不在 status polling 路径刷新（避免 2 秒轮询不必要的注册表访问）。

状态文本示例：
- `Login startup: Enabled`
- `Login startup: Disabled`
- `Login startup: Mismatch — Registered command needs repair.`
- `Login startup: Error — Registration unavailable.`
- `Login startup: Disabled — Registered command needs repair. (Not registered — save App Settings to repair)`

## Settings dirty 规则说明

- `RefreshStartupRegistrationStatusAsync()` 更新 `StartupRegistrationStatusText` 不设置 `IsDirty=true`
- 后台刷新不覆盖 `StartAppOnWindowsLogin` 草稿值
- 后台刷新不触发注册表写入或删除（`RegisterAsync/UnregisterAsync` 只在 `SaveAppSettingsAsync` 中调用）
- `Refresh` 只读取 OS 状态并更新只读提示，不提交用户草稿
