# 阶段 12.3：安装包选型与最小安装包

> 本文件属于 `下一步计划：安装包与发布体验 MVP（2026-07-07）` 的子阶段计划。
> 阶段总览、架构原则、安装包选型建议等共享内容见同目录 `README.md`。

## 阶段目标

选定安装包技术并实现最小可工作的安装包，能把 App + Agent 安装到固定目录并创建开始菜单快捷方式。

## 行为要求

```text
1. 先做安装包选型 spike，按以下顺序评估 MSIX / WiX / Inno Setup：
   - 是否支持当前用户安装（默认无需管理员权限）。
   - 是否能满足托盘常驻、HKCU Run Key 自启、自定义卸载清理。
   - 是否支持可选删除 %LocalAppData%\WUJI 数据目录。
   - 未签名情况下安装体验如何（SmartScreen、杀软误报、用户信任）。
   - 记录每个选项的验证结果和阻塞点。
2. 如果 MSIX / WiX 在以上任一点存在不可接受的阻塞，MVP 允许直接 fallback 到 Inno Setup，并在完成说明中记录选型理由。
3. 选定技术后实现最小安装包，包含 App exe 和 Agent exe（名称以 12.1 最终确定为准，如 QuantifiedSelf.Windows.App.exe / QuantifiedSelf.Windows.Agent.exe 或 WUJI.exe / WUJI.Agent.exe）。
4. 安装到固定目录（默认 %LocalAppData%\Programs\WUJI 或用户选择）。
5. 创建开始菜单快捷方式（快捷方式显示名使用 WUJI，目标指向实际 exe 名）。
6. 安装包版本号与 Directory.Build.props 一致。
7. 支持静默安装参数（可选，为后续 CI 测试预留）。
8. 构建脚本可一键生成安装包。
```

## 验收标准

- 在干净 Windows 环境可运行安装包。
- 安装后安装目录存在 App exe 和 Agent exe（名称与 12.1 最终确定一致）。
- 安装后开始菜单出现 WUJI 快捷方式。
- 安装后 App exe 可正常启动。
- 安装包 build 脚本可用。
- 完成说明记录选型理由，并包含 spike 验证的 4 项结果（当前用户安装、HKCU Run Key / 自启、卸载清理、未签名体验）。

## 建议测试

```text
Installer_InstallsAppExe
Installer_InstallsAgentExe
Installer_CreatesStartMenuShortcut
Installer_InstallPathIsPredictable
```

## 不做什么

- 不写 HKCU Run Key（留到 12.4）。
- 不创建桌面快捷方式（可选）。
- 不做卸载清理（留到 12.4）。
- 不做自动更新。
