- MainWindowViewModel 兼容有无 RefreshService 两条路径

## 审核修复（2026-07-02）

审核发现 3 个问题，均已修复（build 0/0, test 203/203）：

1. RefreshService 路径绕过 `_refreshGate` 导致整次刷新不再防重入 —— MainWindowViewModel.RefreshAsync 统一在分支前获取 `_refreshGate`，覆盖 status + page data 整次刷新；RefreshService 内部 gate 不再被 ViewModel 依赖

2. status 刷新失败后 `RefreshResult.Status = new AgentStatusSnapshot()` 会覆盖真实 UI 状态 —— RefreshViaServiceAsync 检查 `Health.LastRefreshError`，故障时跳过 `RefreshCommonStatus` 只显示错误文案，不用默认快照覆盖顶部状态和按钮状态

3. 测试未覆盖生产路径 —— 新增 `MainWindowViewModel_RefreshUsesRefreshService`；`CreateMainWindowViewModelAsync` 新增可选 `RefreshService` 参数

4. status 失败后仍调用 `RefreshCurrentPageDataAsync` 用默认快照刷页面 —— status 失败时同时跳过 `RefreshCommonStatus` 和 `RefreshCurrentPageDataAsync`，仅显示安全错误，不拿默认快照刷 Dashboard/Diagnostics
