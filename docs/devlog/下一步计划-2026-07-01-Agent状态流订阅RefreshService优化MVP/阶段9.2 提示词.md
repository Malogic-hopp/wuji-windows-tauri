任务目标：

实现“阶段 9.2：Agent status 集中轮询 GetStatus”。

本阶段新增轻量 Agent 状态轮询机制，让 Agent 状态更新频率和页面数据刷新频率解耦。状态刷新使用阶段 8 已完成的 `IPC GetStatus` 优先路径，并保留 `runtime_state / health_state` fallback。

尤其注意本阶段不做：

- 不做真正长连接状态流。
- 不做 Named Pipe stream / subscribe 协议。
- 不推送 Samples / Sessions / Apps 数据。
- 不把 SQLite 查询搬到 IPC。
- 不调整 SQLite 查询服务。
- 不改变当前页数据刷新频率和范围。
- 不改 WPF 页面布局。
- 不改 Agent 命令语义。
- 不改 Named Pipe IPC 协议。
- 不写 agent_events 记录每次状态轮询。
- 不写新的 JSONL / runtime refresh health 文件。
- 不做托盘、自启、安装包。
- 不做命令执行后的 500ms fast polling；这只是后续增强。
