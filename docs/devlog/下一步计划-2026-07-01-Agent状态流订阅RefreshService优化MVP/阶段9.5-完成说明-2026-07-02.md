## Diagnostics RefreshHealth 展示说明

RefreshHealthText 单行综合展示：

```
Refresh loop: <Healthy/Degraded/Refreshing/Ready>  |  Status: last=<时间>, error=<安全文本>, skipped=<N>  |  Page: last=<时间>, error=<安全文本>, skipped=<N>, page=<页名>  |  Intervals: status polling 2s, page refresh <N>s
```

可区分 status refresh 和 page refresh 的独立健康信息。
