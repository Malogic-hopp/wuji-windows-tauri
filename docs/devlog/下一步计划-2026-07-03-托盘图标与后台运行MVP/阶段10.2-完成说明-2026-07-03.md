## TrayService / TrayMenuState 设计说明

- TrayService 通过 ITrayIconAdapter 解耦 NotifyIcon，构造函数接收 Show/Exit 回调
- 不依赖 AgentControlService / AgentProcessService / AgentStatusService / RefreshService / MainWindowViewModel
- 双重点击和 Show 菜单统一走 OnShowMainWindowMenuClicked → TryPostToDispatcher
- Exit 菜单走 OnExitAppMenuClicked → TryPostToDispatcher

## NotifyIcon 依赖与图标 fallback

- 使用 System.Windows.Forms.NotifyIcon，图标 fallback 为 SystemIcons.Application

## Show / Exit 行为

- Show：恢复窗口 Show() + Normal 窗口状态 + Activate()
- Exit：调用 trayService.Dispose() + Application.Shutdown，不 Stop Agent
