# 阶段 10.3：CloseToTray / MinimizeToTray / Show / Exit 语义

## 阶段目标

实现后台运行基础语义：关闭或最小化主窗口时隐藏到托盘，而不是直接退出 App。

## 行为要求

```text
CloseToTray=true:
    点击窗口 X 时 Hide 主窗口。
    Cancel Closing。
    App 继续运行。
    Agent 不被停止。
    status polling 继续运行。
    不 Dispose TrayService。
    不 Shutdown App。

MinimizeToTray=true:
    主窗口最小化时 Hide 主窗口。
    App 继续运行。
    status polling 继续运行。
    托盘 Show 可恢复窗口。

Show Main Window:
    Show()。
    WindowState 从 Minimized 恢复为 Normal。
    Activate()。
    Bring to foreground 尽力即可，不做强制前台 hack。

Exit App:
    设置显式退出标记。
    允许窗口真正关闭。
    StopStatusPolling。
    Dispose TrayService。
    Application.Shutdown。
    不默认 Stop Agent。
```

## 关键语义

```text
关闭主窗口不等于停止 Agent。
隐藏到托盘不等于退出 App。
只有托盘 Exit App 才是真正退出 WPF App。
托盘 Exit App 也不默认停止 Agent。
```

`Exit App` 不得调用：

```text
StopAgentCommand
StopAgentGracefullyAsync
Pause
ClearHistory
任何 Agent 命令
```

## 页面刷新语义

阶段 10 不改变阶段 9 页面自动刷新语义：

```text
CloseToTray / MinimizeToTray 后：
    status polling 继续运行。
    page refresh timer 暂按现有语义继续。
    不在本阶段新增“窗口隐藏后暂停 page refresh”的资源优化。
```

隐藏后是否暂停 page refresh 留到后续优化。

## Show Main Window 语义

托盘 Show 只做最小可靠恢复：

```text
Show()
WindowState = Normal
Activate()
```

不要为了强制置顶或抢焦点引入复杂 Win32 前台窗口 hack。  
如果 Windows 拒绝前台激活，允许退化为任务栏闪烁或普通激活。

## 验收标准

```text
关闭窗口后 App 仍在进程中
Agent 不被停止
status polling 继续运行
托盘 Show 能恢复窗口
Show 恢复时 WindowState 从 Minimized 变为 Normal
Show 不引入复杂 Win32 强制前台 hack
Exit App 后 WPF App 退出
App 退出时不会误发 Stop Agent
AppSettings 中 CloseToTray / MinimizeToTray 生效
```

## 不做什么

```text
不做开机自启
不做 Exit App + Stop Agent 组合操作
不新增 Settings UI 配置项，除非现有 Settings 页面已有入口且改动很小
不改变页面自动刷新语义
```
