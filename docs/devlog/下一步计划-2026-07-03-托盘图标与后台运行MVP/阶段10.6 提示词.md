要求：

```text

Start 菜单项可用。
Pause / Resume / Stop 禁用。

```

2. Stale 状态。

要求：

```text

Stale + IsRunning=true: Stop 可用，Start 禁用。
Pause / Resume 在 Stale 下保守禁用。
状态从 Stale 恢复到 Running / Paused 后，tooltip 和菜单自动恢复。
```

3. IPC unavailable / fallback 状态。

要求：

```text

错误文本应复用现有安全短句或 DiagnosticMessageSanitizer。
IPC 恢复后 tooltip 和菜单自动恢复为 NamedPipe 状态。
托盘 tooltip / menu 中 IPC fallback 只显示简短 source，例如 IPC: FileFallback / unavailable；详细错误仍留在 Diagnostics，不放进托盘。
```

4. Maintenance 状态。

要求：

```text
tooltip 显示 Maintenance 或等价安全短句。
Start / Pause / Resume / Stop 控制命令禁用。

```

5. 状态恢复验收。

要求：

```text

状态恢复时 MainWindow 和托盘菜单状态不漂移。
托盘更新必须来自 MainWindowViewModel 已应用的最新 AgentStatusSnapshot / TrayMenuState；不得在托盘层单独根据临时状态直接覆盖菜单。
Settings dirty 不受托盘状态更新影响。
```
