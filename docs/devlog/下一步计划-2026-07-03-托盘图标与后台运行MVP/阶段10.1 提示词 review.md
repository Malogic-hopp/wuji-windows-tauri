# 建议补强 2：确保 disabled trigger 不被 hover/pressed 覆盖

WPF 样式里常见问题是 disabled trigger 写了，但 hover/pressed trigger 后执行导致视觉被覆盖。建议补一句：

```text id="yc4bg7"
确认 disabled trigger 的视觉优先级不会被 MouseOver / Pressed trigger 覆盖；禁用态下 hover 不应显示为可点击状态。
```

这个对实际体验很关键。
