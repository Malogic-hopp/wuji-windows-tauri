## AgentCommandServer 行为

- 启动：HostedService.ExecuteAsync → 用 `WindowsIdentity.GetCurrent().User.Value` 构造 AgentPipeName → `server.StartAsync(pipeName.FullPipeName, handler, cancellationToken)`
- 停止：CancellationToken 取消 → server 退出监听循环 → pipe 释放
- 每连接处理：`WaitForConnectionAsync` → `HandleConnectionAsync`（ReadMessageAsync → handler → WriteMessageAsync） → DisposeAsync
- 单请求串行处理，保持实现简单

## Ping 行为

- 返回 `Accepted=true, Completed=true, Message="Pong", ActualState=当前状态, StartedAtUtc/CompletedAtUtc 非默认值`

## GetStatus 行为

- 返回 `Accepted=true, Completed=true, Status={...}`
- Status 字段来源：AgentStateMachine.ActualState、ProcessId、LastHeartbeatUtc、LastSampleUtc、CreateRuntimeSnapshot()、CreateHealthSnapshot()
- 包含：actualState、processId、startedAtUtc、lastHeartbeatUtc、lastSampleUtc、currentSessionId、version、isHealthy

## 错误处理

- Unsupported protocol version → `Accepted=false, Completed=false, ErrorCode="UnsupportedProtocolVersion"`
- Unsupported command → `Accepted=false, Completed=false, ErrorCode="UnsupportedIpcCommand"`
- IpcProtocolException（非法 JSON / truncated / oversized）→ 捕获，返回安全 errorCode 和 message，不泄露原始 payload
- 通用异常 → `ErrorCode="IpcProtocolError"`，仅日志记录异常类型名
- 监听循环异常 → `Task.Delay(1000)` 后继续

## 审核修复（2026-07-01）

审核发现 3 个问题，均已修复（build 0/0, test 161/161）：

1. Unsupported command 将客户端原始 command 回显到 Message —— 改为固定文案 `"Unsupported IPC command."`，新增测试验证路径式命令（`C:\Users\...\secret.txt`）不回显

2. GetStatus 的 `DesiredState` 硬编码为 `Running` —— AgentStateMachine 不跟踪持久 DesiredState，改为 `null`，避免客户端误判按钮可用性

3. IPC server 早期异常可能逃出 HostedService —— `NamedPipeServerStream` 构造移入 try/catch；HostedService.ExecuteAsync 新增泛化 catch 记录安全日志后退出而非 fault

4. Server 监听异常后缺 delay 可能形成热循环 —— catch 后新增 `await Task.Delay(TimeSpan.FromSeconds(1), cancellationToken)`，取消时 break 退出循环
