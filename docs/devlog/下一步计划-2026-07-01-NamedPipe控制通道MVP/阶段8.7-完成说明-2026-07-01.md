## 风险复核结论

- IPC 不卡 UI：connect/request timeout 分离，失败快速 fallback
- 双通道不重复执行：IPC 防重 + timeout 不 fallback + file fallback 复用 requestId
- IPC 与 file fallback 语义一致：均通过 ProcessCommandAsync
- 无跨用户控制风险：pipe name 绑用户 SID hash
- agent_control.json 稳定链路保留
- Diagnostics 不泄露 FullPipeName/SID/路径/异常/JSON
- AgentCommandServer 不拖垮采样（独立 BackgroundService + 外层 catch + 1s delay）
- Stop 不留 stale agent_control.json
- ClearHistory 仍需 CLEAR 二次确认
