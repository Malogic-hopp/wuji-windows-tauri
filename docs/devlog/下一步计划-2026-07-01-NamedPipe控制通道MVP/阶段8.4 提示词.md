1. Agent server 支持基础控制命令。

```text

Resume
Stop
ReloadConfig
```

```text

Accepted
Completed
ActualState

ErrorCode
```

3. WPF AgentControlService 改为 IPC 优先。

当前文件：

- src\QuantifiedSelf.Windows.App\Services\AgentControlService.cs

要求：

- 构造函数可新增可选 `IAgentIpcClient?` 和 `AgentIpcStatusService?` 依赖，保持已有测试可构造。

- 如果 IPC Stop 发送后 pipe broken，但随后进程消失或 runtime_state = Stopped，可视为 Stop 成功。
