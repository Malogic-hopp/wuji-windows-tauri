# 阶段 8.1 完成说明（2026-07-01）

Build: `0 warnings / 0 errors` | Test: `153 / 153 passed`（142 原有 + 11 新增）

## 阶段目标回顾

定义 IPC 协议模型、pipe 命名规则和基于 Stream 的 length-prefixed JSON 协议读写。本阶段是纯协议层和基础设施层，不创建真实 Named Pipe server/client。

## 修改/新增的文件

### Core 层（协议模型）

- src/QuantifiedSelf.Windows.Core/Ipc/IpcProtocolException.cs
  —— 新增 IPC 协议异常类型，携带 ErrorCode 和 safe message

- src/QuantifiedSelf.Windows.Core/Ipc/AgentIpcRequest.cs
  —— IPC 请求模型：ProtocolVersion(1)、RequestId(ipc-*)、Command(string)、DesiredState、RequestedBy、RequestedAtUtc、WaitForCompletion、TimeoutMilliseconds
  —— Command 使用 string 类型，兼容共享 AgentCommandType 字符串值（Pause/Resume/...）和 IPC-only 命令（Ping）
  —— DesiredState 复用 AgentDesiredState，JsonStringEnumConverter 序列化

- src/QuantifiedSelf.Windows.Core/Ipc/AgentIpcResponse.cs
  —— IPC 响应模型：ProtocolVersion、RequestId、Accepted、Completed、ActualState、Message、ErrorCode、StartedAtUtc、CompletedAtUtc

- src/QuantifiedSelf.Windows.Core/Ipc/AgentIpcStatus.cs
  —— IPC 状态模型：ActualState、DesiredState、ProcessId、StartedAtUtc、LastHeartbeatUtc、LastSampleUtc、CurrentSessionId、Version、IsHealthy

- src/QuantifiedSelf.Windows.Core/Ipc/AgentPipeName.cs
  —— Pipe 命名：对 user SID 做 SHA-256 hash + hex 编码
  —— FullPipeName = `QuantifiedSelf.Windows.Agent.<full-hash>`（内部连接用）
  —— DisplayPipeName = `QuantifiedSelf.Windows.Agent.<hash前12位>`（Diagnostics 用）
  —— 同一 SID 稳定，不同 SID 不同，不暴露原始 SID

### Infrastructure 层（协议读写）

- src/QuantifiedSelf.Windows.Infrastructure/Ipc/NamedPipeProtocol.cs
  —— 静态类，基于 Stream 实现 length-prefixed UTF-8 JSON 读写
  —— MaxPayloadBytes = 16 KB
  —— ReadMessageAsync 校验：负数 length、超大 payload、半截消息、非法 JSON → 安全 IpcProtocolException
  —— 错误 message 不泄露原始 payload 内容

### 测试

- tests/QuantifiedSelf.Windows.Tests/DataFlowTests.cs
  —— 新增 10 个 IPC 测试，3 个 using（Core.Ipc、Infrastructure.Ipc、System.Text.Json）

## 新增测试

- AgentIpcRequest_RoundTripsJson —— JSON 序列化/反序列化，含枚举和可选字段
- AgentIpcResponse_RoundTripsJson —— 同上，覆盖 Accepted/Completed/ErrorCode=null
- AgentPipeName_GeneratesStableNameForUserSid —— 同一 SID 两次调用产生相同 Full/Display/SidHash
- AgentPipeName_DoesNotExposeRawSid —— Full/Display/SidHash 均不含原始 SID 字符串
- AgentPipeName_UsesDifferentNamesForDifferentUsers —— 不同 SID 产生不同 FullPipeName 和 SidHash
- AgentPipeName_ExposesSafeDisplayName —— Display 只截取 hash 前 ≤12 位，Full 比 Display 长
- NamedPipeProtocol_RoundTripsLengthPrefixedJson —— MemoryStream roundtrip 写入/读取 AgentIpcRequest
- NamedPipeProtocol_RejectsInvalidPayloadSafely —— 合法 length prefix + 垃圾 JSON → IpcProtocolError，message 不含原始内容
- NamedPipeProtocol_RejectsPayloadOverMaxSize —— length prefix 超过 16 KB → IpcPayloadTooLarge
- NamedPipeProtocol_RejectsTruncatedPayloadSafely —— length 声称 100 字节但只写了 10 → IpcProtocolError
- NamedPipeProtocol_RejectsWritePayloadOverMaxSize —— 构造超大 RequestId 使 JSON > 16 KB，WriteMessageAsync 抛出 IpcPayloadTooLarge
