## 2. 阶段 0 决策

ADR-001 已接受以下决策：

```text
React 19
  -> 白名单 Tauri commands/events
Tauri 2 Rust Shell
  -> 私有 stdin/stdout NDJSON JSON-RPC
.NET Client.Bridge
  -> IWujiClient
Application + Client + Core
  -> Infrastructure / Agent
```

生命周期不变量：

- Tauri 窗口关闭不等于 Agent stop；
- Bridge shutdown/EOF/cancellation 都只 Dispose `IWujiClient`；
- `IWujiClient.DisposeAsync()` 不停止 Agent；
- 阶段 1 Bridge 不访问 `IWujiClient.Agent`；
- 只有后续显式 `agent.stop` 用例可以停止 Agent。

阶段 1 只允许 `dev` channel。Bridge 默认 dev，并拒绝 prod/custom；React 尚不存在，也没有传入 channel/path 的入口。

## 6. Bridge 协议

固定值：

- JSON-RPC：`2.0`；
- API：`1.0`；
- encoding：strict UTF-8；
- framing：NDJSON；
- 默认单条上限：1 MiB；
- 默认请求超时：10 秒；
- stdout：只允许 response；
- stderr：只允许安全宿主日志。

已实现 method：

| method | 行为 |
|---|---|
| `bridge.hello` | 协商 API 版本并返回 Bridge version/capabilities |
| `client.initialize` | 幂等调用 `IWujiClient.InitializeAsync()`，返回安全 context |
| `bridge.shutdown` | 返回 accepted 后退出并 Dispose Client |

initialize 只返回：

- API version；
- channel name；
- product display name；
- isDefaultChannel；
- capability names。

不返回 path、SID、用户名、机器名、pipe、进程、设置或 runtime state。

## 7. 输入与错误处理

Bridge 对以下情况返回稳定安全错误：

- 非法 JSON 或非法 UTF-8；
- 非 object/缺字段/未知字段；
- 非法 request/correlation id；
- params 含阶段 1 未允许字段；
- 超过 payload 上限；
- 未完成 hello 即 initialize；
- 不兼容 API major；
- 不在白名单的方法；
- request id 被不同 method 复用；
- initialize timeout；
- 未分类 Client 异常。

同一 id + method 返回缓存 response，不重复执行。缓存上限为 128 条，避免无界增长。

`BoundedNdjsonReader` 在读取时限制 payload，而不是先分配任意长度字符串再检查；超限消息会被丢弃到本行结束，随后可以继续处理下一条合法请求。

未分类异常不把 `Exception.Message` 或 stack trace写入 stdout/stderr。安全日志只记录已校验 method 和 correlation id。

## 8. 生命周期验证

自动测试覆盖：

- hello → initialize → shutdown；
- 多个 initialize id 仍只初始化一次；
- 相同 request id 返回相同缓存 response；
- initialize before hello 不访问 Client；
- timeout 后仍能 shutdown；
- host cancellation 取消 initialize 并 Dispose；
- stdin EOF Dispose；
- shutdown/EOF/cancellation 都不读取 `IWujiClient.Agent`；
- internal exception/path 不进入 stdout/stderr；
- real `WujiClientFactory` 在 dev channel 完成 hello/shutdown。

真实 composition smoke 没有调用 initialize，因此不会创建或修改 dev 数据目录；它只验证 Windows identity/Client composition 和 Bridge 生命周期能被真实入口组装。
