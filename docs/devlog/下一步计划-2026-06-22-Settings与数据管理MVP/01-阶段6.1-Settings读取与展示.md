# 阶段 6.1：Settings 读取与展示

## 阶段目标

让 Settings 页能清晰展示当前配置和数据路径，但暂不编辑。

这阶段只做低风险读取和展示，为后续编辑、保存、ReloadConfig 建立页面结构。

## 当前问题

当前 Settings 仍主要内嵌在 `MainWindow.xaml` 中，能展示部分 JSON，但缺少：

```text
独立 SettingsView
独立 SettingsViewModel
结构化 App Settings 展示
结构化 Agent Options 展示
配置路径展示
配置读取失败的安全错误态
```

## 错误处理

要求：

```text
配置缺失时显示默认值
JSON 读取失败时显示安全错误文本
错误文本不暴露本机敏感路径
页面不崩溃
```

## 验收标准

- SettingsView 独立 UserControl。
- SettingsViewModel 能读取 App Settings。
- SettingsViewModel 能读取 Agent Options。
- 配置缺失时显示默认值，不报错。
- JSON 读取失败时显示安全错误文本。
- 打开数据 / 日志 / 配置目录按钮可用。
- Dashboard / Apps / Sessions / Samples / Diagnostics 不回归。

## 建议测试


## 不做什么

- 不编辑配置。
- 不保存配置。
- 不发送 ReloadConfig。
- 不做隐私规则编辑。
- 不做 PruneData / ClearHistory。
