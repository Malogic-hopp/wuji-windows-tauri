# 阶段 13.5：Insight Suggestions 规则建议

## 阶段目标

新增第一版本地规则建议，把统计结果转化为温和、具体、可执行的行动提示。

一句话目标：

```text
让 WUJI 不只告诉用户发生了什么，也给出下一步可以怎么调整。
```

## 建议类型

第一版建议可以包含：

```text
高切换建议
    30 分钟内切换频繁，建议安排一个 25 分钟单任务块。

专注不足建议
    今天缺少较长连续专注段，建议挑一个低打扰时间段做深度任务。

异常应用占比建议
    某个应用今日占比明显高于最近 7 天平均，建议复盘是否符合预期。

开始/结束偏移建议
    今天开始明显偏晚或结束明显偏晚，建议明天提前安排第一块工作。

正向反馈
    今天最长专注段高于最近平均，给予轻量正反馈。
```

## 行为要求

```text
1. 建议由本地规则生成，不调用网络，不调用 AI。
2. 建议必须带 EvidenceText，说明依据。
3. 建议必须带 ActionText，给出具体行动。
4. 文案必须温和，不评价人格，不使用羞辱性表达。
5. 同一类建议每天最多显示 1 条，避免刷屏。
6. 建议数量有限制，Dashboard 第一版最多显示 3 条。
7. 没有足够数据时显示中性空状态，不编造建议。
8. 不做系统通知，不弹窗打扰。
9. 规则阈值必须可测试、可记录。
10. 建议生成失败不影响 Dashboard 基础统计展示。
```

## 验收标准

```text
1. 能基于高切换生成建议。
2. 能基于专注段不足生成建议。
3. 能基于 7 天平均生成异常应用占比建议。
4. 数据不足时不生成误导建议。
5. Dashboard 展示建议标题、依据和行动。
6. build/test 通过，0 warnings / 0 errors。
```

## 建议测试


## 不做什么

```text
不做 AI 建议
不做通知弹窗
不做任务管理
不做目标系统
不做云端规则
不做用户画像
```
