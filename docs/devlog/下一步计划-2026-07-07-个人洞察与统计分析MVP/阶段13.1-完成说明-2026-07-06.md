## 今日日期边界策略

使用本地日期（`DateOnly.FromDateTime(DateTime.Now)`）计算 UTC 时间范围：

```
localStart = localDate.Date (00:00 local) → ToUniversalTime()
localEnd = localStart + 1 day → ToUniversalTime()
```

取 `app_sessions` 中与 UTC 范围有重叠的 session：
- `started_at_utc < rangeEndUtc`
- `COALESCE(ended_at_utc, nowUtc) > rangeStartUtc`

跨天 session 按重叠比例缩放持续时间（与现有 `OverviewQueryService` 和 `AppUsageQueryService` 一致）。

## 数据来源

| 指标 | 数据源 | 查询方式 |
|---|---|---|
| `TotalDurationSeconds` | `app_sessions` | 读取重叠 session，C# 侧重叠缩放累加 |
| `TotalActiveDurationSeconds` | `app_sessions` | 同上 |
| `TotalIdleDurationSeconds` | `app_sessions` | 同上 |
| `SessionCount` | `app_sessions` | 重叠 session 数量 |
| `SampleCount` | `foreground_samples` | `SELECT COUNT(*)` WHERE today |
| `FirstSeenAtUtc` | `app_sessions` + `foreground_samples` | MIN(started_at_utc) 合并 MIN(sample_time_utc) |
| `LastSeenAtUtc` | `app_sessions` + `foreground_samples` | MAX(COALESCE(ended_at_utc, now)) 合并 MAX(sample_time_utc) |
| `TopApps` | `app_sessions` | 复用 `AppUsageQueryService.GetAppUsageForLocalDayAsync`（SQL CTE 重叠缩放） |
| `TopWindows` | `foreground_samples` | 按 `(window_title, process_name)` 分组，按 sample_count DESC, window_title ASC 排序 |

## 排序稳定性

- **TopApps**：`active_duration_seconds DESC → total_duration_seconds DESC → process_name COLLATE NOCASE ASC`
- **TopWindows**：`sample_count DESC → window_title COLLATE NOCASE ASC`

## 隐私过滤策略

窗口标题通过 `DiagnosticMessageSanitizer.CreateSafeText()` 处理后展示：
- Windows 路径（如 `C:\Users\...`）被替换为 `<path>`
- 控制字符被替换为空格
- 多余空白被压缩
- 截断到 120 字符

原始窗口标题保留在 `WindowTitle` 字段中（内部使用），`SafeWindowTitle` 提供安全展示。

## 错误处理

`DailyStatsService.GetTodaySummaryAsync()` 在以下情况下返回空摘要：
- 数据库文件不存在
- 数据库表不存在
- 查询过程中发生任何异常

空摘要特征：所有时长为 0，列表为空，Date 为当天。不抛出未处理异常，不泄露数据库路径、SQL、原始异常堆栈。
