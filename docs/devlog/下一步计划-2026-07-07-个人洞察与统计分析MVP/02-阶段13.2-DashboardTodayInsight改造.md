# 阶段 13.2：Dashboard Today Insight 改造

## 阶段目标

把阶段 13.1 的今日摘要接入 Dashboard，让首页从“数据显示页”升级为“今日洞察页”。

一句话目标：

```text
打开 WUJI 第一眼就能知道今天主要发生了什么。
```

## 实施范围

Dashboard 第一版建议展示：

```text
今日活跃时长
今日记录时间范围
Top Apps
Top Windows / Titles
Session 数量
样本数量
今日摘要一句话
```

展示原则：

```text
1. 信息密度适中，优先清晰。
2. 不做营销式 hero。
3. 不做复杂图表。
4. 保持现有 WPF 风格和控件层次。
5. 不让页面刷新阻塞 status polling。
```

## 行为要求

```text
1. DashboardViewModel 通过 DailyStatsService 获取今日摘要。
2. 不把 SQL 查询写进 ViewModel。
3. Refresh 当前页时可刷新 Today Insight。
4. status polling 不得刷新 Today Insight。
5. 页面刷新失败时保留旧 Dashboard 数据，不清空已有洞察。
6. Settings dirty 不影响 Dashboard 统计刷新。
7. 今日无数据时显示空状态，而不是错误。
8. 所有时间和时长格式统一、易读。
9. TopApps / TopWindows 数量有限制，避免页面过长。
10. 不改 Start / Pause / Resume / Stop 按钮语义。
```

## 验收标准

```text
1. Dashboard 显示今日活跃摘要。
2. Dashboard 显示 Top Apps。
3. Dashboard 显示 Top Windows / Titles。
4. 点击 Refresh 后今日摘要可更新。
5. 2 秒 status polling 不触发 DailyStatsService 页面查询。
6. 查询失败时旧数据保留，错误安全展示。
7. build/test 通过，0 warnings / 0 errors。
```

## 建议测试

```text
Dashboard_LoadsTodayInsightFromDailyStatsService
Dashboard_RefreshUpdatesTodayInsight
Dashboard_StatusPollingDoesNotReloadTodayInsight
Dashboard_StatsFailureKeepsPreviousInsight
Dashboard_EmptyStatsShowsEmptyState
Dashboard_DoesNotOverwriteSettingsDrafts
```

## 不做什么

```text
不做 7 天趋势
不做建议引擎
不做 focus session 计算
不改 Samples / Sessions / Apps 页面
不新增安装包逻辑
```
