## 刷新路径说明

| 触发 | 更新 Dashboard Insight? | 说明 |
|---|---|---|
| 用户点击 Refresh | ✅ 是 | `RefreshAsync` → `RefreshCurrentPageDataWithGateAsync` → `RefreshDashboardAsync` → `DashboardViewModel.LoadAsync()` |
| 15 秒定时页面刷新 | ✅ 是 | 同样走 `RefreshAsync` 路径 |
| 2 秒 status polling | ❌ 否 | `RefreshStatusOnlyAsync` → `PerformStatusPollAsync` → 仅 `RefreshCommonStatus`，不触发页面刷新 |
| 切换到 Dashboard 标签 | ❌ 否 | 只改变 `SelectedTabIndex`，不主动刷新 |

## status polling 不刷新页面数据的验证

`PerformStatusPollAsync` 调用 `_refreshService.RefreshStatusAsync()` 后仅调用 `RefreshCommonStatus()` 更新 Agent 状态相关属性（AgentStatusText、LastHeartbeatText 等），**不调用** `RefreshCurrentPageDataWithGateAsync`。因此 2 秒轮询永远不会触发 `DashboardViewModel.LoadAsync()`。

## 空状态和错误状态

| 场景 | 行为 |
|---|---|
| 无今日数据 | 显示"暂无今日活动数据。Agent 运行并写入数据后会显示在这里。"全部统计为 `0m`/`0`/`-` |
| 数据库不存在 | DailyStatsService 返回空摘要 → Dashboard 显示空状态 |
| 查询异常 | `HasLoadError = true`，**保留上一次成功加载的数据**，不清空已有洞察 |
| 首次加载即失败 | `_lastSummary` 为 null → 全部清空显示初始空状态 |
