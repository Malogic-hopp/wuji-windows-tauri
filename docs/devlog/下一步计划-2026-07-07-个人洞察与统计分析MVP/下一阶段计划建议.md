# 下一阶段计划建议（2026-07-06）

阶段 13 完成后，WUJI 已具备完整的本地个人洞察能力。以下是后续方向建议。

## 短期建议（1-2 周内）

### 1. 安装包与卸载体验（阶段 12 续）

阶段 12 已产出 self-contained release exe 和图标，但缺少安装包。建议推进：

- 选型安装包工具（WiX Toolset / Inno Setup / MSIX）
- 桌面快捷方式
- 开始菜单入口
- 卸载与残留清理

**优先级**：高。当前用户需手动运行 exe，安装包是正式使用的前提。

### 2. 洞察阈值可配置

当前 Focus/ContextSwitch/Suggestion 的阈值都是代码常量。建议暴露到 Settings UI：

- 最小专注时长、最大间隔、最大切换数
- 建议开关（关闭不想要的建议类型）

**优先级**：中。让用户微调规则，减少误报。

### 3. 手动验证完成

完成 [阶段 13 验收清单](./阶段13-验收清单-2026-07-06.md) 中的手动验证项目，确认长跑稳定。

**优先级**：高。当前仅自动化测试通过，需人工确认 UI 表现。

## 中期建议（1 个月内）

### 4. 周报生成

基于 7 天趋势自动生成一段可读周报摘要（Markdown 文本，可复制）：

- 本周活跃总时长 vs 上周
- 最专注的一天
- 最高切换的一天
- Top 应用变化

**优先级**：中。不用图表，文本即可。

### 5. 数据导出

CSV / JSON 导出 DailyActivitySummary、趋势数据。用于用户自己分析或备份。

**优先级**：中。

### 6. 热力图增强

- 时间段背景带叠加（睡觉/上午/下午/晚上半透明色带）
- 点击单元格查看该小时的 Top Apps
- 虚线分隔 6/12/18 点

**优先级**：低。当前纯色矩阵已可用。

## 长期建议

### 7. 目标设定与轻量提醒

用户设定每日目标（如"活跃 4 小时"、"专注 1 小时"），Dashboard 显示进度。

**优先级**：低。避免做成任务管理系统。

### 8. 数据备份与恢复

SQLite 数据库备份到指定目录，支持从备份恢复。

**优先级**：低。

### 9. 多设备同步

可选：本地网络同步或手动导入/导出。

**优先级**：低。用户量增长后再考虑。

## 当前可忽略

- 云同步 / 账号体系（用户量 < 10 时不值得）
- AI 大模型建议（本地规则已够用）
- 复杂报表系统（导出 CSV 让用户自己分析）
- 月报 / 年报（7 天趋势可扩展但非优先）
- 番茄钟 / 强提醒（违背"温和教练"定位）
- 全局快捷键
- 屏幕截图分析

## 软件定期维护事项（非阶段计划）

### 应用语境分类规则维护

这不是阶段 14 / 阶段 15 之类的新功能主线，而是 WUJI 长期使用时需要定期做的小维护：随着用户安装新工具、访问新网站，内置分类规则会出现未覆盖项，需要温和地提示用户补充分组。

维护目标：

```text
1. 系统先用内置规则自动分类。
2. 定期扫描最近 7 天数据库，找出未分类 / 低置信度的进程、浏览器标题或域名。
3. 只提示出现次数 >= 10 或活跃时长 >= 5 分钟的未知项，避免噪音。
4. 在 Dashboard 或 Settings 中提示“有 N 个未分类应用/网站可整理”，不弹窗打断。
5. 用户选择分类后写入本地配置，后续统计和洞察优先使用用户规则。
```

建议分类集合：

```text
Development
Research
Study
Communication
Entertainment
System
Productivity
Other
```

建议扫描对象：

```text
ProcessName:
    zotero.exe -> Study
    obsidian.exe -> Study
    some-new-tool.exe -> 待用户确认

BrowserTitleOrDomain:
    github.com -> Development
    bilibili.com / xiaohongshu.com / weibo.com -> Entertainment
    unknown-site.example -> 待用户确认
```

维护约束：

```text
1. 每天最多提示一次。
2. 不在 2 秒 status polling 中扫描数据库。
3. 不上传标题、域名或进程名。
4. 未分类项只显示安全摘要，避免泄露完整本机路径或敏感标题。
5. 用户规则必须可编辑、可删除、可重置为内置默认。
```
