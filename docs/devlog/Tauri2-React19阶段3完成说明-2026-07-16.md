## 5. BridgeSupervisor（阶段 3B）

### 5.1 固定进程边界

开发时 Bridge 只从以下固定位置启动：

```text
src-tauri/sidecars/bridge/QuantifiedSelf.Windows.Client.Bridge.exe
```

`pnpm bridge:prepare` 只把现有 Bridge 的 Debug、framework-dependent 输出准备到该目录。Rust 固定追加：

```text
--channel dev
```

React command 不接受 path、channel、dataRoot、Pipe、Agent executable 或任意 method 字符串。release 路径预留为宿主 executable 同级的隔离 `bridge/` 目录；正式复制和 installer 布局仍属于阶段 7。

### 5.2 启动与协议

单一 Supervisor 启动后按顺序执行：

```text
spawn Bridge
  -> bridge.hello
  -> API major version / capabilities 检查
  -> client.initialize
  -> Ready(generation)
```

运行期维护：

- UUID request/correlation id；
- `request id -> oneshot responder`；
- stdout NDJSON 响应读取；
- 1 MiB 消息上限；
- 查询与命令 timeout；
- Agent stop 独立 22 秒宿主 timeout；
- 未知 id、非法包络、双 result/error、超限和 stdout EOF 检测；
- stderr 只记录行长度摘要，不复制 raw 日志到 UI。

### 5.3 崩溃与恢复

- Bridge EOF、退出或协议流损坏会使当前 pending request 以安全错误结束；
- 首次非正常失败退避 350 ms 后自动重启一次；
- 重启重新执行 hello 和 initialize；
- 30 秒内再次失败打开 circuit，不再 crash loop；
- 稳定运行至少 30 秒后重新获得一次自动重启额度；
- `bridge_retry` 是唯一手动恢复 command；
- 每次 Ready 都增加 generation，并发出 `bridge://availability` 安全事件；
- React 收到新 Ready generation 后重置 initialize 与 Agent status query；
- unavailable/circuit_open 显示可恢复断线状态。

事件只包含 `state` 和 `generation`，不包含路径、channel、PID、异常或运行时数据。

### 5.4 shutdown

Tauri 退出时：

1. Supervisor 状态切换为 ShuttingDown；
2. 拒绝新请求并结束 pending responder；
3. 发送 `bridge.shutdown`；
4. 等待 Bridge 正常退出；
5. 超时后只 kill Bridge 子进程。

该路径没有 `agent.stop`，不会隐式停止 Agent。Bridge 的 `IWujiClient.DisposeAsync()` 语义继续由阶段 1/2 的 .NET 生命周期测试冻结。

## 6. command、capability 与 CSP

WebView 只可调用：

```text
app_initialize
agent_get_status
agent_start
agent_pause
agent_resume
agent_stop
bridge_retry
```

不存在 `execute(method)`、任意 shell、任意 sidecar、文件、SQL、HTTP、Named Pipe 或进程 command。

`capabilities/main.json` 只绑定 `main` window 和 Tauri core default，不安装或授权 shell、fs、http、sql、process、upload、opener 插件。

CSP 以以下边界为核心：

```text
default-src 'self'
script-src 'self'
object-src 'none'
frame-src 'none'
base-uri 'self'
form-action 'none'
```

仅为 Tauri 内部 IPC 允许 `ipc:` 与 `http://ipc.localhost`。没有 `unsafe-eval`、远程脚本、远程字体、iframe 或远程导航。

## 7. React 最小可用 UI（阶段 3C）

### 7.1 应用框架

- React 19 StrictMode；
- 顶层 ErrorBoundary；
- TanStack Query provider；
- Hash Router；
- Dashboard 与 Settings 页面级 lazy import；
- mutation 默认 `retry=false`；
- initialize/status 查询允许有限重试；
- Agent status 每 4 秒刷新；
- Agent command 成功后 invalidate status；
- Bridge Ready generation 后 reset initialize/status。

### 7.2 Agent 顶栏

顶栏显示中文状态与健康说明，并提供 start/pause/resume/stop。操作执行中禁用冲突按钮，过渡状态不允许重复命令，side-effect 失败不自动重试。

断线状态明确说明“Agent 会保持原状态运行”，并提供“重新连接”。前端没有把 Bridge 断线解释为 Agent 已停止；单个 Agent command 的业务失败只显示安全操作提示，不会被误报为 Bridge 断线。

### 7.3 路由与无障碍

- Dashboard 与 Settings 均可从主导航进入；
- `Alt+1` / `Alt+2` 支持键盘切换；
- 提供“跳到主要内容”链接；
- 路由变化后焦点进入页面主标题；
- 所有操作使用 button 和可见 focus ring；
- 状态变化使用 `aria-live`，断线使用 `role=alert`；
- 图标均来自本地 Phosphor SVG 并与中文标签同时出现；
- 不使用 emoji 作为结构图标。

### 7.4 视觉系统

建立 primitive/semantic CSS token 骨架，覆盖：

- Light；
- Dark（`prefers-color-scheme`）；
- Windows High Contrast（`forced-colors`）；
- `prefers-reduced-motion`；
- 中文 Windows 系统字体栈；
- 稳定 surface、border、focus、positive、warning、danger 语义色。

没有加载远程字体或远程视觉资源。Tauri Windows resource 复用现有 WPF `Resources/app.ico`，架构测试冻结两份 icon 内容一致。
