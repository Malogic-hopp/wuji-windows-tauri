## 1. 实施范围

本批只完成阶段 4A“合同与 Bridge”：

- 在唯一 schema 中加入 `activity.getOverview`；
- 定义今日摘要、Top Apps、最近会话的安全 Dashboard DTO；
- 重新生成 C#、Rust、TypeScript 合同；
- Bridge 只通过 `IWujiClient.Activity.Overview` 获取数据；
- 同时启动三个独立查询并聚合为一次响应；
- 增加 10 秒只读查询 timeout、initialize 门禁和固定 capability；
- 增加合同漂移、并发、映射、隐私和安全异常测试。

本批没有增加 Tauri command，没有修改 React Dashboard，也没有改动 Application 查询语义、Infrastructure/SQLite、WPF、IPC、Agent 或发布流程。

## 2. 合同

新增方法：

```text
activity.getOverview
```

新增生成类型：

```text
ActivityGetOverviewParams
ActivityOverviewResult
ActivityOverviewSummary
ActivityOverviewApp
ActivityOverviewSession
```

响应结构：

```text
ActivityOverviewResult
├─ summary
├─ topApps[]
└─ recentSessions[]
```

`summary` 只包含日期、总时长、活跃/空闲/未知时长和会话数。`topApps` 只包含安全显示名、时长、会话数和最后使用时间。`recentSessions` 只包含安全显示名、开始/结束时间和时长。

合同明确不包含：

- 原始窗口标题；
- 进程名；
- 会话数据库 ID；
- 数据库路径、数据根目录或可执行文件路径；
- 用户名、机器名、Pipe 信息；
- raw exception、stack trace 或内部错误详情。

## 3. Bridge 聚合

Bridge handler 先取得唯一入口：

```text
IWujiClient.Activity.Overview
```

随后同时启动：

```text
GetDashboardSummaryAsync()
GetTopAppsTodayAsync(limit: 5)
GetRecentSessionsAsync(limit: 5)
```

三个查询全部完成后才通过显式 `BridgeActivityMapper` 生成 schema DTO。Bridge 不调用 `Activity.Apps`、`Activity.Sessions`，不引用 Infrastructure，也不出现 SQLite 查询。

`activity.getOverview` 必须在 hello 和 initialize 后调用，使用独立 10 秒 timeout，属于无副作用查询。异常由现有 allowlist 错误模型统一映射为安全 `internal_error` 或 `request_timeout`，stdout/stderr 不包含异常消息和内部路径。

## 4. 隐私处理

- `AppSession.Id`、`ProcessName`、`WindowTitle` 在 mapper 中完全不可见；
- Top Apps 的内部 `ProcessName` 不进入合同；
- 只使用 Application 已解析的 `DisplayName`；
- 显示名为空时返回“未知应用”；
- 显示名意外包含目录时只保留最后一段；
- 去除控制字符并把显示名限制为 128 个字符；
- 时长和计数以 schema `minimum: 0` 约束，异常负值在 mapper 中归零；
- UTC 时间统一使用 round-trip `O` 格式。
