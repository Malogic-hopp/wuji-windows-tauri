## 1. 分阶段实施顺序

### 阶段 1：设计系统 + 产品外壳（预计 2-3 天）

**目标**：建立统一的 Design Token 系统、拆分主题资源、实现新侧边栏导航、简化 Agent 状态展示、迁移所有旧页面入口。

**具体任务**：

1. **拆分 AppTheme.xaml 为多文件**：
   - `Colors.xaml` — 基础色板（扩展当前 17 个颜色 → 30+ 语义颜色）
   - `Brushes.xaml` — 语义画刷（页背景、卡片背景、文字等级、状态色、上下文分类色）
   - `Typography.xaml` — 字体样式（DisplayLarge, TitleMedium, BodyLarge, MetricValue, Caption 等）
   - `Cards.xaml` — 卡片样式（MetricCard, ContentCard, InsightCard）
   - `Buttons.xaml` — 按钮样式（Primary, Secondary, Ghost, NavButton, AgentStatusButton）
   - `Navigation.xaml` — 侧边栏样式（NavItem, NavItemSelected, ShellSurface）
   - `DataGrid.xaml` — 保留现有 DataGrid 样式

2. **重写 MainWindow.xaml**：
   - 左侧导航栏（184-208px）+ 顶部页面栏 + 主内容区
   - 新导航按钮（今天/时间线/洞察/趋势 + 分隔 + 数据与隐私/设置）
   - 简化 Agent 状态（圆点 + "正在记录" 文本 + 弹出菜单）

3. **创建 ShellViewModel**：
   - 从 MainWindowViewModel 提取导航逻辑
   - 管理 PrimaryNavigationItems / SecondaryNavigationItems
   - NavigateCommand 保留字符串参数，兼容旧 NormalizePageKey

4. **创建 AgentStatusViewModel**：
   - 从 MainWindowViewModel 提取 Agent 状态展示
   - 简化按钮：只显示一个主操作按钮（开始/暂停/恢复）
   - "停止后台服务" 放入更多菜单

5. **旧页面入口迁移**：
   - Dashboard → TodayView（先保留旧的 Dashboard 内容）
   - Apps/Sessions/Samples → TimelineView（TabControl 内嵌）
   - Insights → InsightsView（保留）
   - Diagnostics → Settings 高级入口
   - Settings → 保留

6. **代码清理**：
   - 删除 TodayPageViewModel / TimelinePageViewModel / TrendsPageViewModel / PrivacyPageViewModel
   - 从 XAML 中移除所有硬编码颜色
   - 用 StaticResource/DynamicResource 替换
