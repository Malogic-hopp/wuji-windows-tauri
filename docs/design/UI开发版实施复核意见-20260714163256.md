## 阻塞验收的问题

### P0 — Insights 仍实际生成并展示未实现的数据语义

**状态：未解决。**  
**证据**：`Views/InsightsView.xaml:115,140` 绑定 `SummaryText` 与 `ActionText`；`ViewModels/InsightsViewModel.cs:224-267` 直接将 `FocusInterruptionInsightService` 的文本和工作块集合应用到页面。服务中仍生成“有效专注”“工作块”“碎片化”“任务切换”等结论（`Services/FocusInterruptionInsightService.cs:276,449-496`），建议引擎同样生成“今天任务切换较频繁”“今天缺少连续专注”等用户文案（`Services/InsightSuggestionEngine.cs:101-135,229-231`）。此外，顶栏副标题仍写“把应用切换、任务切换和中断解释清楚”（`ViewModels/MainWindowViewModel.cs:1341`）。

虽然 `InsightsView.xaml:176` 声明不会使用这些术语，但实际绑定的数据会使用它们，免责声明因而不成立。

**修复方向**：在 ContextSegment / WorkBlock 可解释数据模型落地前，Insights 应移除服务推断、建议和相关集合，只呈现应用切换、窗口切换、会话、采样等事实；同步修正顶栏副标题与回归测试。

**验收标准**：Insights 的任何可见文本均不把应用级样本或会话解释为任务、专注、工作块、碎片化或上下文切换。

### P1 — 深色与高对比主题仅有未接入的基础代码

**状态：未解决。**  
**证据**：`Services/ThemeService.cs` 中 `ThemeService` 除自身定义外没有调用点，用户界面也没有主题选择入口。`ApplyTheme(HighContrast)` 在 `ThemeService.cs:32-37` 调用 `RemoveBrushDictionaries`；后者却在 `:78-80` 重新加载浅色 `Brushes.xaml`，没有高对比资源字典或 `SystemColors` 回退。`App.xaml:7-16` 仍固定加载浅色字典与遗留 `AppTheme.xaml`。

这不能满足“可运行时切换 Light / Dark / High Contrast”的既定验收标准；深色资源文件存在并不代表主题可用。

**修复方向**：将主题服务接入设置和应用启动；以三套完整的语义 Brush 字典实现 Light/Dark/High Contrast，其中高对比使用 `SystemColors` 或等价系统资源；移除遗留字典对同名资源的覆盖。

**验收标准**：运行时可选择三种主题并立即更新页面、导航、DataGrid、图表文字、焦点和热力图边界；高对比不回退为浅色主题。

### P1 — 960×640 紧凑布局没有落实到任何页面

**状态：未解决。**  
**证据**：`AdaptiveLayout.Mode` 的 XAML 使用仍仅存在于 `MainWindow.xaml`，`Views/` 目录没有任何消费点。Today 的 MetricStrip 仍固定为四列（`Views/TodayView.xaml:36-84`），底部仍固定双栏（`:183-235`）；Insights、Trends、Privacy 的指标条和双栏同样没有 Compact 模板。虽然 `MainWindow.xaml` 已将最小尺寸改为 960×640，但仅侧栏会收起。

**修复方向**：在各页面根据 `AdaptiveLayout.Mode=Compact` 切换为 2×2 MetricStrip、单栏模块和必要的图表横向滚动；为该行为添加 View 层集成测试。

**验收标准**：960×640 时不出现文字裁切、指标挤压或双栏并排；1280×800 保持四列与双栏。

### P1 — 设计令牌收口和“无嵌套卡片”不只剩 Settings 问题

**状态：未解决。**  
**证据**：`InsightsView.xaml:121-145` 在摘要卡内嵌建议卡，并直接设置 `CornerRadius="8"`、`Padding="14"`、`FontSize="12"`；`PrivacyView.xaml:46-82,96-124,144-177` 在大卡内反复嵌套视觉卡；`TrendsView.xaml:101-126,153-170` 也保留卡内卡与硬编码圆角/内边距。Today 仍有 `CornerRadius="6"`、`Padding="10,8"` 等页面级硬编码（`TodayView.xaml:110-123`）。

**修复方向**：将页面级尺寸迁移到语义样式/令牌；建议、隐私摘要与周度摘要改为分隔线、背景层或内联文本，而非嵌套 ContentCard。

**验收标准**：除 `Themes/` 外不新增或保留页面级 `FontSize`、`CornerRadius`、`Padding`；主要信息结构不存在卡片套卡片。

## 未完成或回归的问题

### P2 — 隐私页仍默认暴露路径，且“高级诊断”不可收起

**状态：未解决。**  
**证据**：`Views/PrivacyView.xaml:95-124` 是普通 `Border`，不是 `Expander` 或可折叠区域；其中直接绑定数据根目录、数据库和日志路径，未见用户名脱敏转换。

**修复方向**：默认折叠该区域，显示前脱敏路径中的用户名；保留“打开数据位置”等明确操作。

### P2 — 热力图可访问性没有完成

**状态：未解决。**  
**证据**：Today 与 Trends 均使用 LiveCharts `CartesianChart` 呈现热力图（`TodayView.xaml:168-174`、`TrendsView.xaml:146-151`），没有单元格键盘导航、`AutomationProperties.Name` 或等价表格摘要。

**修复方向**：提供逐格可访问的热力图实现，或提供能通过键盘和自动化工具读取的等价数据表/摘要。

### P2 — 仍有字符箭头和英文加载错误

**状态：未解决。**  
**证据**：Insights 日期导航仍使用 `‹` / `›`（`InsightsView.xaml:19,32`）；`InsightsViewModel.cs:187-190` 仍输出 `Insights load failed` 英文错误。

**修复方向**：日期导航改为带自动化名称的图标资源；加载失败文案改为中文安全提示。
