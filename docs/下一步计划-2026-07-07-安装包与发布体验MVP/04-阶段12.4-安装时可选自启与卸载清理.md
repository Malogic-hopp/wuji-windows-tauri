# 阶段 12.4：安装时可选自启与卸载清理

> 本文件属于 `下一步计划：安装包与发布体验 MVP（2026-07-07）` 的子阶段计划。
> 阶段总览、架构原则、安装包选型建议等共享内容见同目录 `README.md`。

## 阶段目标

让安装包支持可选的开机自启，并确保卸载时清理注册表和快捷方式。

## 行为要求

```text
1. 安装时提供可选选项：
   - 开机自动启动 WUJI（默认不勾选或勾选，需在完成说明中明确）。
2. 如果用户勾选，安装包必须优先通过 App exe 命令行接口注册自启：
   - 阶段 12.4 先新增 `<AppExeName> --register-autostart` / `--unregister-autostart` 命令行入口（如 WUJI.exe 或 QuantifiedSelf.Windows.App.exe），内部复用阶段 11 的 StartupRegistrationService。
   - 该命令必须是 headless：不创建主窗口、不创建托盘图标、不启动 status polling、不触发 AutoStartAgentWhenAppStarts、不启动 Agent；执行成功后立即退出，返回 exit code 0，失败返回非 0。
   - 命令内部发生错误时，输出安全文案，不得泄露完整路径、用户名、SID 等敏感信息。
   - 安装包调用该命令完成安装时自启注册 / 取消注册。
   - 只有当命令行接口暂未实现或安装器技术限制时，才允许安装包直接写 HKCU Run Key。
   - 如果安装包直接写，必须完全复用 StartupCommandBuilder 的 command 规则，并在完成说明中记录风险。
3. 卸载前应检测 WUJI App / Agent 是否正在运行：
   - MVP 可提示用户先退出 WUJI。
   - 不得默认静默强杀 Agent。
   - 如需强制关闭，必须由用户明确确认。
   - 卸载不应在 App / Agent 仍运行时删除正在使用的 exe。
4. 卸载时删除 HKCU Run Key 中的 WUJI value。
5. 卸载时删除开始菜单快捷方式。
6. 卸载时删除安装目录。
7. 卸载时默认保留 %LocalAppData%\WUJI\WindowsAgent 数据目录。
8. 提供可选"同时删除用户数据"复选框，默认不勾选。
```

补充要求：

```text
删除用户数据必须是显式选项，默认不勾选。
卸载程序不得静默删除 SQLite / JSONL / app-settings.json / windows-agent.json。
如果用户选择删除数据，完成说明必须记录删除范围。
```

## 验收标准

- 安装时勾选自启后，HKCU Run Key 出现 WUJI value。
- 安装时不勾选自启后，HKCU Run Key 不出现 WUJI value。
- `<AppExeName> --register-autostart` / `--unregister-autostart` 命令执行时不创建主窗口、不创建托盘图标、不启动 Agent、不启动 status polling。
- 命令成功返回 exit code 0，失败返回非 0。
- 命令错误输出不包含完整路径、用户名、SID。
- 卸载后 HKCU Run Key 中 WUJI value 被删除。
- 卸载后安装目录被删除。
- 卸载后开始菜单快捷方式被删除。
- 卸载后数据目录默认保留。
- build/test 通过。

## 不做什么

- 不做自动更新。
- 不做 Windows Service。
- 不改阶段 11 StartupRegistrationService 的核心逻辑。
