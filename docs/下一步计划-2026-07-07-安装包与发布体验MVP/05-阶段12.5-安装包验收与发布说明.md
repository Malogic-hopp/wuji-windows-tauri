# 阶段 12.5：安装包验收与发布说明

> 本文件属于 `下一步计划：安装包与发布体验 MVP（2026-07-07）` 的子阶段计划。
> 阶段总览、架构原则、安装包选型建议等共享内容见同目录 `README.md`。

## 阶段目标

生成发布说明、版本号文档，并在干净环境验证安装包全流程。

## 行为要求

```text
1. 生成发布说明文档，包含：
   - 版本号
   - 发布日期
   - 最低系统要求（Windows 10/11、.NET 运行时依赖说明）
   - 安装步骤
   - 卸载步骤
   - 已知问题
   - 升级建议
2. 在干净 Windows 环境（或虚拟机）验证：
   - 安装
   - 启动 App
   - 启动 Agent
   - 托盘常驻
   - 开机自启
   - 卸载
3. 记录任何安装包相关问题。
```

## 验收标准

- 发布说明文档已落盘。
- 干净环境安装后 App 可启动。
- 干净环境安装后 Agent 可启动。
- 干净环境安装后托盘正常。
- 干净环境安装后自启可工作（如果安装包支持）。
- 卸载后无残留注册表项和安装目录。
- 如果安装包未签名，发布说明必须标注 `unsigned MVP installer`，并记录 SmartScreen / 杀软误报 / 用户信任风险。

## 建议测试

```text
ReleaseNotes_HasVersionAndRequirements
CleanInstall_StartsApp
CleanInstall_StartsAgent
CleanInstall_AutostartWorks
CleanInstall_UninstallLeavesNoRunKey
```

## 不做什么

- 不做 CI/CD 自动发布。
- 不做签名证书（如未获得）。
- 不做自动更新。
