## 3. 实际行为与失败语义（P2-03）

原缺陷：`ipc_graceful_shutdown()` 失败只 `print` 不加入 `failures`，Agent 随后
exit 0 时报告仍可能 `verdict=pass`——与"hello 和 shutdown 两次响应都必须成功"
的声明不一致。

修复：

1. `ipc_graceful_shutdown` 返回结构化 `(hello_ok, shutdown_ok, will_exit, note)`，
   三个受控条件分别显式记录（hello 拒 / shutdown 拒 / willExit 缺失 / IPC 传输失败）。
2. 退出判定提取为纯函数 `controlled_exit_failures(shutdown_attempted, hello_ok,
   shutdown_ok, will_exit, exit_code, forced_kill, agent_exited_early) -> list[str]`：
   - **任一受控退出条件失败都返回失败项（verdict=fail）**；
   - **Agent 提前自行 exit 0 也失败**（未走受控路径）；提前退出时不再重复检查
     hello/shutdown/willExit（一条"提前退出"即 fail）；
   - 超时强杀 fail；正常路径 exit code 非 0 fail。
3. `main()` 用纯函数结果组装 `failures`，报告 `gracefulShutdown` 显式记录 7 项：
   `shutdownAttempted` / `helloOk` / `shutdownOk` / `willExit` / `note` /
   `exitCode` / `forcedKill`。
4. 删除了旧的 `if forced_kill` / `if not crashes and exit_code != 0` 重复判定
   （并入纯函数），避免重复失败项。
