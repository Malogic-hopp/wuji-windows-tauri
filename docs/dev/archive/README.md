# 文档归档约定（archive/）

本目录存放**已收口工作线**的过程文档（审核/评审/整改/阶段完成说明），遵循：

1. **只读**：归档文档是历史证据，不修改内容、不据其判定当前完成度。移动用 `git mv` 保留历史。
2. **命名**：`<工作线>-<日期>/`（如 `第四阶段整改-2026-07-23/`、`统计主页评审/`、`历史审核/`、`设计评审/`）。
3. **内部链接**：归档文档内的相对链接以**原位置**（docs/dev 根）为基准，移入归档后不保证有效性；引用以活跃文档（docs/dev 根：09 基线、10/11、migration-status、README）为准。
4. **归位时机**：每个阶段/工作线收口后（完成说明 + 门禁通过 + 产品确认）移入；活跃权威文档（01–09、10/11、ADR、migration-status）始终留在根目录。
5. **验收证据**：soak-report、package manifest 等归 `docs/dev/evidence/<版本>/`，不留在 `dist/`（构建产物目录）。
