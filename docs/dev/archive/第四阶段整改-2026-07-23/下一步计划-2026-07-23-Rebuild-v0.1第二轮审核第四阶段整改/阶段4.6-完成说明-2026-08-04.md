## 3. 场景映射（P2-01 的 10 类核心失败场景 → 真实拓扑测试）

真实拓扑 = `CaptureCoordinator → BarrierRequest → Capture Loop → CapturePipelineItem FIFO
→ Processor → Writer data lane + control lane → SQLite/SharedState`。两个层级：
- **完整链（含 CaptureCoordinator）**：`wiring()`（lock_sleep_lifecycle/settings_effectivity）
  经 `control_plane::assemble` 生产组装，`apply_*` 命令产生 BarrierRequest；
- **生产链路段（Capture Loop→Processor→Writer）**：barrier_reliability 的真实拓扑测试
  （BarrierRequest 由测试经专用通道注入 Capture Loop，非直接向 Writer data lane 注入）。
`fixture()`（barrier_reliability）为 Writer 单测 fixture（不经 control_plane）。
直接向 Writer 注入 ProcessorOutput 的测试仅作 Writer 单元测试保留，不替代真实接线。
