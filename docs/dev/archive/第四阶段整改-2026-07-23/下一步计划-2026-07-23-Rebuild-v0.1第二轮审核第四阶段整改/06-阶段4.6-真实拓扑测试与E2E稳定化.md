# 阶段 4.6：真实拓扑测试与 E2E 稳定化

## 阶段目标

关闭 P2-01、P2-02：用真实生产拓扑证明 4.1–4.5 的不变量，并消除父进程存活
E2E 的进程定位 flaky。

## 真实测试拓扑

核心测试必须经过：

```text
CaptureCoordinator
→ BarrierRequest
→ Capture Loop
→ CapturePipelineItem FIFO
→ Processor
→ Writer data lane + control lane
→ SQLite/SharedState
```

直接向 Writer 注入 ProcessorOutput 的测试只能作为 Writer 单元测试。

## 必须覆盖

1. backlog 与 Barrier 顺序；
2. Sample/Barrier 同时 ready；
3. Barrier 先于 control；
4. channel Full/Closed 与任务退出；
5. 两级 queue drop 后 Barrier 可达；
6. Settings 规则边界；
7. Lock/Sleep 与 Pause/Stop 叠加；
8. pending TTL/overflow/冲突；
9. 失败后 DB/shared/watch/DTO 一致；
10. CommandServer 与 reconciler 无旁路。

## E2E 稳定化

`agent_survives_parent_exit_and_offline_read_works_after_kill` 必须使用确定性的 PID、
进程句柄或握手定位目标 Agent，不依赖全局映像名扫描和模糊时间窗口。失败清理只能
作用于当前唯一 `rebuild-v01-test-*` channel。

## 验收标准

- 新增真实拓扑 harness；
- 第四阶段审核列出的核心失败场景全部有测试；
- Agent E2E 串行通过；
- `cargo test --workspace` 连续两次完整通过，不 skip；
- 首次失败和最终结果写入完成说明。

## 明确不做

- 不运行正式 package/8h soak；
- 不执行真实 Lock/Sleep；
- 不更新 v0.1 为验收完成。
