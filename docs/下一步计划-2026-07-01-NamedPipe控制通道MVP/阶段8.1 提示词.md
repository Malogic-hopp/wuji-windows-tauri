6. 新增 Infrastructure 层 NamedPipeProtocol。

建议文件：

- src\QuantifiedSelf.Windows.Infrastructure\Ipc\NamedPipeProtocol.cs

协议要求：

- 使用 length-prefixed UTF-8 JSON。
- 基于 `Stream` 实现读写，不依赖真实 NamedPipeStream。
- 支持 `CancellationToken`。
- `MaxPayloadBytes = 16 * 1024`。
- 超过上限时抛出或返回安全协议错误，错误码建议 `IpcPayloadTooLarge`。
- 非法 JSON、半截 payload、负数 length、异常 length 都要安全失败。
- 失败时不要把原始 payload 内容放进异常 message。

建议 API：

```csharp
public static class NamedPipeProtocol
{
    public const int MaxPayloadBytes = 16 * 1024;

    public static Task WriteMessageAsync<T>(
        Stream stream,
        T message,
        CancellationToken cancellationToken = default);

    public static Task<T> ReadMessageAsync<T>(
        Stream stream,
        CancellationToken cancellationToken = default);
}
```

如果更符合项目风格，也可以做成实例类，但本阶段不要引入真实 pipe 连接。
