# 阶段 5.2：SamplesView MVP

## 阶段目标

让用户能看到最近前台采样明细。

这一页用于验证：

```text
真实采样是否持续写入
窗口标题是否已脱敏
activity_state 是否符合 active / idle / unknown 口径
excludedProcesses 是否确实没有进入 samples
```

## 前置条件

阶段 5.1 已完成：

```text
SampleQueryService.GetRecentSamplesAsync(limit = 200)
```

## 交付物

建议新增：

```text
src/QuantifiedSelf.Windows.App/Views/SamplesView.xaml
src/QuantifiedSelf.Windows.App/ViewModels/SamplesViewModel.cs
```

如果现有项目结构暂时不适合完整 View + ViewModel，本阶段至少拆出：

```text
SamplesView UserControl
```

不要把 SamplesView 全部继续堆进 `MainWindow.xaml`。

## 页面内容

第一版展示：

```text
Local time
Process
Display name
Window title
Idle seconds
Activity state
Sample id
```

`executable_path` 第一版默认不展示。  
如确实需要，放到详情区域，并且只显示文件名或脱敏路径。

完整路径只在 Diagnostics / 开发排错场景查看，避免路径中的用户名、项目名或隐私目录进入普通数据浏览页。

## 基础交互

第一版支持：

```text
Refresh
最近 200 条
ActivityState 筛选：All / Active / Idle / Unknown
```

## 隐私要求

必须保证：

```text
maskWindowTitles=true 时，window_title 为空或显示 [Masked]
excludedProcesses 命中时，不应出现对应 sample
不要在 UI 辅助文案中暴露被过滤标题
如果当前表结构无法区分空标题和脱敏标题，第一版统一显示 [Hidden]
不要为了区分空标题 / 脱敏标题改采样表结构
```

## 验收标准

- SamplesView 能显示最近 200 条样本
- 按 `sample_time_utc DESC, id DESC` 排序
- ActivityState 筛选可用
- 空表显示友好空态
- 窗口标题脱敏不回归
- 默认不展示完整 `executable_path`
- 大量数据下刷新不卡顿

## 建议测试

```text
SamplesViewModel_LoadsRecentSamples
SamplesViewModel_FiltersByActivityState
SamplesViewModel_ReturnsEmptyStateForEmptyDatabase
SamplesView_DoesNotExposeExecutablePathByDefault
```

## 不做什么

- 不做全文搜索
- 不做任意日期选择
- 不做无限滚动
- 不做导出
- 不做复杂筛选
