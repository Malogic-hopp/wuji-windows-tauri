# 阶段 5.4：AppsView MVP

## 阶段目标

让用户能看到应用维度的今日使用排行。

这一页用于回答：

```text
今天主要用了哪些应用？
Active / Total / Idle / Unknown 分布如何？
哪个应用最近使用过？
应用排行是否符合 active duration 口径？
```

## 前置条件

阶段 5.1 已完成：

```text
AppUsageQueryService.GetAppUsageForLocalDayAsync(DateOnly localDate, int limit = 50)
```

## 页面内容

第一版展示：

```text
Rank
Display name
Process name
Active duration
Total duration
Idle duration
Unknown duration
Session count
Last used local time
```

## 排行口径

第一版使用：

```text
active_duration_seconds DESC
total_duration_seconds DESC
process_name ASC
```

原因：

```text
active_duration 更接近真实使用
total_duration 容易被长时间 idle 虚高
```

## 展示名 fallback

必须保证：

```text
display_name -> process_name -> Unknown
```

同时保留现有产品显示名映射：

```text
QuantifiedSelf.Windows.App -> WUJI
QuantifiedSelf.Windows.Agent -> WUJI Agent
```

## 基础交互

第一版支持：

```text
Refresh
Today
Top 50
```

接口保留 `localDate` 参数：

```csharp
GetAppUsageForLocalDayAsync(DateOnly localDate, int limit = 50)
```

第一版 UI 只传 Today，后续扩展 7 天排行时不推翻查询服务。

## 验收标准

- AppsView 能显示今日应用排行
- 排行按 active duration 降序
- active 相同时按 total duration 降序
- total 相同时按 process_name 升序
- display_name fallback 正确
- WUJI / WUJI Agent 展示名映射不回归
- session_count 正确
- last_used_time 正确
- 空数据时显示友好空态
- 同时展示 Active / Total / Idle / Sessions，避免用户误解排序口径
