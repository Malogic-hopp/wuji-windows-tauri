## 阶段完成情况

### 阶段 5.1 查询服务

已完成：

- `SampleQueryService.GetRecentSamplesAsync(limit = 200)`。
- `SessionQueryService.GetRecentSessionsAsync(limit = 200)`。
- `SessionQueryService.GetSessionsForLocalDayAsync(localDate, limit = 200)`。
- `SessionQueryService.GetSessionsOverlappingRangeAsync(startUtc, endUtc, limit = 200)`。
- `AppUsageQueryService.GetAppUsageForLocalDayAsync(localDate, limit = 50)`。
- 查询服务使用只读 SQLite 连接。
- 列表查询有 `LIMIT`。
- 缺库 / 缺表返回空列表。
- Apps 查询在 SQL 层完成聚合、排序和 LIMIT。

### 阶段 5.2 SamplesView MVP

已完成：

- 独立 `SamplesView` 和 `SamplesViewModel`。
- 最近 200 条 Samples。
- `All / Active / Idle / Unknown` 筛选。
- 不展示完整 `ExecutablePath`。
- 空标题显示 `[Hidden]`。
- 加载失败时 UI 文本走路径脱敏。
- 空态和错误态区分。

### 阶段 5.3 SessionsView MVP

已完成：

- 独立 `SessionsView` 和 `SessionsViewModel`。
- `Today / Last 24 Hours / Recent` 范围切换。
- `All / Open / ProcessChanged / Paused / Stopped / Other` close reason 筛选。
- open session 的 ended time 显示 `正在进行`。
- 不展示 `WindowTitle`。
- `SelectedRange` 快速切换时使用 load version 防止旧结果覆盖新结果。

### 阶段 5.4 AppsView MVP

已完成：

- 独立 `AppsView` 和 `AppsViewModel`。
- Today Top 50。
- 展示 Rank / Display name / Process name / Active / Total / Idle / Unknown / Sessions / Last used。
- display name fallback：`display_name -> process_name -> Unknown`。
- WUJI / WUJI Agent 产品名映射不回归。
- 加载失败时 UI 文本走路径脱敏。

### 阶段 5.5 导航与页面收口

已完成：

- 导航顺序调整为 `Dashboard / Apps / Sessions / Samples / Diagnostics / Settings`。
- `NavigationPages` 集中管理页面顺序。
- `SelectedTabIndex`、`CurrentPage`、`LastSelectedPage` 和 `OpenSettingsCommand` 复用同一套映射。
- 全局 Refresh 改为刷新公共 Agent 状态后，只刷新当前页面数据。

### 阶段 5.6 验收稳定化与收口

已完成：

- Dashboard Top Apps 复用 `AppUsageQueryService.GetAppUsageForLocalDayAsync`。
- Dashboard Top Apps 与 AppsView Today 排行口径统一。
- 新增口径一致性回归测试，覆盖跨日 session 和 open session。
- 新增完成情况说明和验收清单。

## 新增或扩展测试
