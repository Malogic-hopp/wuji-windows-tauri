你是 coding agent。请在现有 WUJI Windows App 中实现一个独立的 `Insights` 页面，用于展示“专注中断洞察 / 工作复盘”。

## 目标

新增一个独立页面：

```text
Insights
```

用于把 `foreground_samples` / `app_sessions` 转换成可解释的工作复盘：

```text
今天为什么切换频繁？
主要中断源是什么？
哪些长工作块被打断？
下一步可以怎么调整？
```

Dashboard 不再继续承载这类深度分析。Dashboard 只保持概览职责。

## 必须实现

### 1. 新增服务层

新增服务，建议命名：

```text
FocusInterruptionInsightService
```

职责：

```text
读取指定本地日期的 foreground samples
计算 raw tool hops
计算 meaningful context switches
识别 work blocks
统计 top interruption sources
统计 top context transitions
生成 summary text 和 action text
```

可以复用或扩展现有只读 query service。不要写数据库。

不要在 WPF App 中调用 Python 脚本。

`scripts/analyze_context_switches.py` 仅作为算法参考和验算工具。

### 2. 新增模型

建议新增到合适位置，例如 `QuantifiedSelf.Windows.Core.Models` 或 App 层 ViewModels/Models：

```csharp
public sealed class FocusInterruptionInsight
{
    public DateOnly Date { get; init; }
    public int ActiveSampleCount { get; init; }
    public TimeSpan EstimatedActiveTime { get; init; }
    public int RawToolHopCount { get; init; }
    public int MeaningfulContextSwitchCount { get; init; }
    public IReadOnlyList<WorkBlockInsight> WorkBlocks { get; init; } = [];
    public IReadOnlyList<InterruptionSourceInsight> TopInterruptionSources { get; init; } = [];
    public IReadOnlyList<ContextTransitionInsight> TopContextTransitions { get; init; } = [];
    public string SummaryText { get; init; } = string.Empty;
    public string ActionText { get; init; } = string.Empty;
}
```

并新增：

```text
WorkBlockInsight

ContextTransitionInsight
```

字段可参考方案文档，不要求一字不差，但 UI 所需信息必须完整。

## Work Block 规则

MVP 建议规则：

```text
只看 Active 样本
相邻 Active 样本间隔 <= 5 分钟则属于同一 block
block 持续时间 >= 25 分钟才进入候选工作块
展示前 4 个
```

有效专注段建议规则：

```text
block >= 25 分钟
meaningful context switch count <= 3
主语境占比 >= 70%
```

如果真实数据中没有有效专注段，不要简单提示“缺少专注”，而要解释：

```text
你有较长工作块，但块内 Communication / System / Entertainment 插入较多。
```

## 文案要求

文案必须温和、具体、可执行。

禁止：

```text
你效率很差
你不专注
你浪费时间
```

推荐：

```text
你今天有 2 段较长开发块，但微信和资源管理器插入较多。
可以尝试一个 45 分钟 Code-only 块，把微信和文件查找集中到块前后处理。
```

## 测试要求

至少新增测试：

```text
1. Code ↔ Codex ↔ Terminal 不计为高风险 meaningful switch。
2. Code ↔ WeChat 计为 Development ↔ Communication。
3. Edge 技术标题归 Research。
4. Edge Bilibili / 微博 / 小红书等标题归 Entertainment。
5. 能识别一个 90 分钟 work block，并统计其中中断源。
6. 无数据时返回安全空 insight。
7. InsightsViewModel LoadAsync 成功填充 Summary / WorkBlocks / Sources。
```

测试不得依赖真实用户数据库。

不要使用长时间 `Thread.Sleep` 或真实 timer。
