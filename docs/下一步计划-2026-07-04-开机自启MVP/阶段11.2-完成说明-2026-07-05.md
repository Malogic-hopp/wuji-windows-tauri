## 审核修复（2026-07-05）

审核发现 2 个问题，均已修复（build 0/0, 0 warnings, test 311/311）：

1. **RegistryStartupRegistry 吞异常，将注册表失败误报为 Disabled** —— `ReadValue` 和 `DeleteValue` 移除 try/catch 包裹。子键/value 不存在仍正常处理（OpenSubKey 返回 null / DeleteValue throwOnMissingValue:false），权限/IO 异常向上抛给 `StartupRegistrationService`，由 service catch 后返回安全 Error 状态。

2. **`CommandsMatch` 用 `Contains` 做参数匹配，会误接受伪参数** —— `--from-autostart-disabled`、`--start-hidden-old` 等会被误判为有效。改为 token 精确匹配：新增 `ExtractArgTokens` 方法，跳过 exe 路径后按空格分词，用 `StringComparer.OrdinalIgnoreCase` 做精确 token 查找。新增测试 `StartupCommandBuilder_DoesNotMatchAutostartArgPrefix`、`StartupCommandBuilder_DoesNotMatchStartHiddenArgPrefix`。

## 阶段目标

新增用户级自启注册服务（`StartupRegistrationService`），能通过 HKCU Run Key 注册、取消注册、读取和检测当前 WUJI 自启状态。本阶段只操作 HKCU Run Key，不写 Settings UI，不改变 App 启动流程。

## IStartupRegistry 设计说明

```csharp
public interface IStartupRegistry
{
    string? ReadValue(string name);
    void SetValue(string name, string command);
    void DeleteValue(string name);
}
```

- 只封装基本注册表读写删除，不解释 command 内容
- 生产实现 `RegistryStartupRegistry` 只写 HKCU，不请求管理员权限
- 测试使用 `FakeStartupRegistry`（内存 Dictionary）隔离

## StartupCommandBuilder 设计说明

| 方法 | 职责 |
|---|---|
| `IsValidProcessPath()` | 当前路径是否为有效 WUJI App exe |
| `BuildCommand()` | 构建 `"<path>" --from-autostart --start-hidden`，无效时返回 null |
| `NormalizeExePath(path)` | 去引号、正斜杠→反斜杠 |
| `ExtractExePath(command)` | 从注册命令中提取 exe 路径 |
| `CommandsMatch(registered)` | 规范化比较：路径匹配 + 两个必要参数都存在 |

路径有效性规则：
- 非空、非 dotnet.exe、必须以 .exe 结尾

命令比较规则：
- 提取 exe 路径 → 规范化 → 大小写不敏感比较
- 检查 `--from-autostart` 和 `--start-hidden` 均存在（大小写不敏感）
- 处理引号、多余空格、正斜杠/反斜杠

## StartupRegistrationStatus 设计说明

| State | 含义 | StatusText |
|---|---|---|
| `Disabled` | WUJI value 不存在 | `Login startup: Disabled` |
| `Enabled` | value 存在且命令匹配 | `Login startup: Enabled` |
| `Mismatch` | value 存在但不匹配（路径不同/缺参数） | `Login startup: Mismatch` |
| `Error` | 注册表读写异常 | `Login startup: Error` |
| `UnsupportedInCurrentLaunchMode` | 当前运行入口无效（如 dotnet.exe） | `Login startup: Unavailable` |

关键规则：
- 已有 Run Key 与当前 App 不匹配 → Mismatch（不是 Unsupported）
- 当前路径无效 + 无已有 Run Key → Unsupported
- 当前路径无效 + 有已有 Run Key → Mismatch

## StartupRegistrationService 设计说明

- value name 固定为 `WUJI`
- Register：构建 command → SetValue → 返回 Enabled / Unsupported / Error
- Unregister：DeleteValue → 返回 Disabled / Error
- GetStatus：ReadValue → CommandsMatch → 返回状态

## 安全脱敏说明

| 检查项 | 结论 |
|---|---|
| StatusText 不含完整路径 | ✅ 仅固定短句 "Login startup: Enabled/Disabled/..." |
| DetailText 不含完整路径 | ✅ 仅 "Registered command needs repair." / "Registration unavailable." 等安全短句 |
| 不含完整 Run Key command | ✅ 不存储/展示原始 command |
| 不含注册表异常原文 | ✅ catch 后使用安全工厂方法 |
| 不含 SID / 用户目录 | ✅ 不拼接任何系统路径 |
| 不含异常类型名 / stack trace | ✅ 统一使用固定安全文案 |
| 不含 HKCU\Software 原始路径 | ✅ 不暴露注册表路径 |
