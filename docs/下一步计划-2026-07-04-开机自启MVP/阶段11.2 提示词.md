3. 新增 `StartupRegistrationStatus` 枚举/模型。

建议新增：

```text
src\QuantifiedSelf.Windows.App\Services\StartupRegistrationStatus.cs
```

状态定义：

```text
Disabled: WUJI value 不存在。
Enabled: WUJI value 存在，且命令指向当前 App，并包含预期参数（--from-autostart 与 --start-hidden）。
Mismatch: WUJI value 存在，但命令不指向当前 App、缺少必要参数或无法解析；建议显示安全 Needs repair 文案。
Error: 读取或写入注册表失败（如权限异常）。
UnsupportedInCurrentLaunchMode: 当前运行入口不是有效 WUJI App exe，无法构建自启命令；已有 Run Key 与当前 App 不匹配时不应返回此项。
```

要求：

```text
StartupRegistrationStatus 是纯模型，不依赖注册表。
可包含安全 StatusText 或 ErrorMessage，但不包含完整路径或注册表异常原文。
```

建议新增：

```text

```

职责：

```text
RegisterAsync(): 注册当前 App 到 HKCU Run Key。
UnregisterAsync(): 从 HKCU Run Key 删除 WUJI value。
GetStatusAsync(): 读取并分析当前注册状态。
```

要求：

```text
依赖 IStartupRegistry 和 StartupCommandBuilder。
注册 value name 固定为 WUJI。
注册 command 使用 StartupCommandBuilder 构建。
Register 幂等：重复注册不产生异常，覆盖为正确命令。
Unregister 幂等：value 不存在时视为成功。
Unregister 只删除 WUJI 自己的 value，不碰其他 Run Key。
Register 发现可执行路径无效时不得写入任何 Run Key，返回 UnsupportedInCurrentLaunchMode 或 Error。
GetStatus 对已有 command 做规范化解析，区分 Disabled / Enabled / Mismatch / Error。
WUJI value 存在但缺少 --from-autostart 或 --start-hidden 时返回 Mismatch。
已有 Run Key 与当前 App 不匹配时返回 Mismatch，而不是 UnsupportedInCurrentLaunchMode。
错误处理安全：不抛原始注册表异常到上层 UI，返回包含安全短句的 StartupRegistrationStatus。
```
