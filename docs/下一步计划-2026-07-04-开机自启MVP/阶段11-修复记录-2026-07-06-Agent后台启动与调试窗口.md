# 阶段 11 修复记录：Agent 后台启动与调试窗口（2026-07-06）

Build: `0 warnings / 0 errors` | Test: `355 / 355 passed`

## 背景

手动验收第 11 项时发现：

```text
AutoStartAgentWhenAppStarts=true
dotnet run --project src\QuantifiedSelf.Windows.App -- --from-autostart --start-hidden
```

App 主窗口没有弹出，托盘 tooltip / App 状态 / Diagnostics 均显示 `Running`，说明 Agent 自动启动成功；但 Agent 被新启动时会弹出 Windows Terminal，不符合自启隐藏的后台体验。

进一步确认：

- Agent 已经运行时，`StartAgentAsync()` 会复用现有进程，不会弹出新终端。
- Agent 未运行且 App 需要启动 Agent 时，会进入 `Process.Start(startInfo)`。
- 原 `ProcessStartInfo` 仅设置了 `UseShellExecute=false`，没有显式设置 `CreateNoWindow=true` / `WindowStyle=Hidden`，因此 console/worker Agent 被新拉起时可能出现终端窗口。

## 修复目标

默认产品体验：

```text
App 启动 Agent 时后台运行，不弹 Windows Terminal。
```

开发调试体验：

```text
需要观察 Agent 控制台日志时，可通过环境变量显式打开调试窗口。
```

## 代码修改说明

### 默认后台启动

`AgentProcessService.ResolveStartInfo()` 现在对 `.exe` 直接启动和 `.dll` 经 `dotnet` 启动两条路径统一应用窗口策略：

```text
UseShellExecute = false
CreateNoWindow = true
WindowStyle = Hidden
```

因此默认情况下，App 通过 Start Agent / AutoStartAgentWhenAppStarts 拉起 Agent 时不会弹 Windows Terminal。

### 调试窗口开关

推荐使用启动参数：

```text
--show-agent-console
```

示例：

```powershell
dotnet run --project src\QuantifiedSelf.Windows.App -- --from-autostart --start-hidden --show-agent-console
```

效果：

```text
CreateNoWindow = false
WindowStyle = Normal
```

同时保留环境变量作为兼容入口：

```text
WUJI_AGENT_SHOW_CONSOLE=1
```

支持值：

```text
1
true
yes
```

设置后，`AgentProcessService` 会保留 Agent 控制台窗口：

示例：

```powershell
$env:WUJI_AGENT_SHOW_CONSOLE = "1"
dotnet run --project src\QuantifiedSelf.Windows.App
```

关闭调试窗口：

```powershell
Remove-Item Env:\WUJI_AGENT_SHOW_CONSOLE
```

### 启动参数与环境变量对比

| 方式 | 推荐场景 | 优点 | 注意事项 |
| --- | --- | --- | --- |
| `--show-agent-console` | 手动验收、临时调试、复现单次启动问题 | 跟随本次命令，意图清楚，不污染后续 PowerShell 会话 | 需要在 `dotnet run` 的 `--` 后面传给 App |
| `WUJI_AGENT_SHOW_CONSOLE=1` | IDE 调试、脚本、快捷方式不方便改参数时 | 对所有启动路径生效，兼容旧修复记录 | 容易遗留在当前 shell，会影响后续启动 |
