## 手动验收

建议至少验证：

```text
1. 默认安装/启动后 StartAppOnWindowsLogin=false。
2. Settings 中开启 Start WUJI on Windows login 后保存成功。
3. HKCU Run Key 中出现 WUJI value。
4. Run Key command 指向当前 App，并包含 --from-autostart --start-hidden。
5. 关闭 Start WUJI on Windows login 后保存成功。
6. HKCU Run Key 中 WUJI value 被删除。
7. 开启自启后模拟登录启动参数运行 App，主窗口不弹出，托盘图标出现。
8. 自启隐藏后托盘 Show 可恢复主窗口。
9. 自启隐藏后 status polling 继续。
10. AutoStartAgentWhenAppStarts=false 时，自启 App 不启动 Agent。
11. AutoStartAgentWhenAppStarts=true 时，自启 App 启动 Agent。
12. 手动启动 App 仍显示主窗口。
13. 注册表 command 被手动改坏后，Settings / Diagnostics 显示 Mismatch / Needs repair。
14. Save 修复 mismatch 后，状态恢复 Enabled。
15. 注册失败或读失败时显示安全错误，不泄露完整路径或异常原文。
16. Exit App 后托盘图标不残留，Agent 不被误停。
17. CloseToTray / MinimizeToTray 行为不回归。
18. 托盘 Start / Pause / Resume / Stop 不回归。
19. Settings dirty 时等待 status polling，不覆盖编辑草稿。
20. 重启 App 后 Settings 显示的自启状态与 OS 注册状态一致。
21. 自启实例存在时再次手动启动 App，观察是否出现双托盘图标、双窗口或状态漂移；如出现，记录为后续前置风险或最小修复项。
```

## 长跑验证

建议做：

```text
1. 启用自启，使用 --from-autostart --start-hidden 启动，隐藏到托盘运行 15-30 分钟。
2. AutoStartAgentWhenAppStarts=true 场景下观察 Agent Running 稳定。
3. AutoStartAgentWhenAppStarts=false 场景下观察 App 常驻但 Agent 不自动启动。
4. Pause / Resume / Stop / Start 从托盘循环 3-5 次。
5. Exit App 后 Agent 不被误停，托盘图标不残留。
6. 再次手动启动 App，主窗口正常显示。
```

## 风险复核

收口前需要确认：

```text
1. StartAppOnWindowsLogin 与 AutoStartAgentWhenAppStarts 语义独立。
2. HKCU Run Key 注册 / 删除幂等。
3. 禁用自启后 WUJI value 不残留。
4. StartupCommandBuilder 不会注册 dotnet.exe / dll / 空路径。
5. Run Key command 比较使用规范化解析。
6. Settings 保存失败时不显示假启用。
7. Settings dirty 不覆盖 StartAppOnWindowsLogin 草稿，不触发注册表写入。
8. AutoStartHidden 不通过 Window.Closing / CloseToTray 模拟隐藏。
9. AutoStartHidden 不弹阻塞式 MessageBox。
10. Diagnostics 不泄露完整路径 / SID / command / 注册表异常原文。
11. 阶段 10 托盘 CloseToTray / MinimizeToTray / Exit App 不回归。
12. 阶段 8 IPC、阶段 9 RefreshService、阶段 7 数据清理不回归。
13. 重复启动行为已手动验证并记录。
```
