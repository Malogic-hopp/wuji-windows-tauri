### 恢复步骤

如果手动验收中修改了 HKCU Run Key 导致注册项异常：
1. 通过 Settings 勾选"登录 Windows 后启动 WUJI" → Save → 自动修复为正确 command
2. 或取消勾选 → Save → 删除 WUJI value
3. 确认 `regedit` 中 Run Key 状态符合预期（Enabled 场景应存在正确条目，Disabled 场景应不存在）

> **提醒**：手动修改注册表仅用于开发验证，普通用户不要手动改。
