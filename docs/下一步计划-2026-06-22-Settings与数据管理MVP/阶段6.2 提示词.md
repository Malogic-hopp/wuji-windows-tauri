实施要求：

1. 在 `SettingsViewModel` 中为 App Settings 增加可编辑字段。
2. 支持编辑：
   - `refreshIntervalSeconds`
   - `autoStartAgentWhenAppStarts`
   - `lastSelectedPage`
3. `refreshIntervalSeconds` 要做基础校验：
   - 必须是整数
   - 建议范围至少不要低于 5 秒
   - 非法时不保存，并给安全、清晰的状态文本
4. `lastSelectedPage` 只能保存现有导航页：
   - Dashboard
   - Apps
   - Sessions
   - Samples
   - Diagnostics
   - Settings
5. 新增 Save App Settings 命令。
6. 保存时调用现有 `SettingsService.SaveAppSettingsAsync`，不要绕开服务直接写文件。
7. 保存成功后更新 `AppSettings` 当前值和展示文本。
8. 保存失败时不要显示原始异常消息，复用 `DiagnosticMessageSanitizer` 做安全错误文本。
9. 保持阶段 6.1 的只读 Agent Options 展示，不要在本阶段编辑 Agent Options。
10. 不要实现 Save Agent Options、Backup、Restore Backup、ReloadConfig。
11. 不要实现 PruneData / ClearHistory。
12. 不要新增托盘、主题之类假入口。
