# 阶段 6.2：App Settings 编辑

## 阶段目标

先支持 WPF 自有配置编辑，建立 Settings 表单、校验、保存和状态提示模式。

App Settings 属于 WPF App 自己，风险低于 Agent 采集域配置，适合作为第一批编辑能力。

## MVP 编辑字段

```text
refreshIntervalSeconds
autoStartAgentWhenAppStarts
```

只读展示：

```text
lastSelectedPage
```

第一版不展示：

```text
theme
minimizeToTray
closeToTray
```

原因：

```text
托盘和主题系统本阶段不做。
不要在 Settings UI 中出现用户以为可用、实际无效果的假入口。
```

## 校验规则

```text
refreshIntervalSeconds
    最小 5
    最大 300

autoStartAgentWhenAppStarts
    bool
```

## 保存语义

```text
点击 Save App Settings
    ↓
校验
    ↓
保存 app-settings.json
    ↓
立即更新 MainWindow 刷新间隔
    ↓
显示保存成功
```

## 错误处理

要求：

```text
无效值不写入
保存失败时显示安全错误文本
保存失败不破坏旧 app-settings.json
```

## 验收标准

- 修改 `refreshIntervalSeconds` 后能保存到 `app-settings.json`。
- 刷新间隔在当前 App 进程内生效。
- 修改 `autoStartAgentWhenAppStarts` 后能保存。
- 无效值不会写入。
- 保存失败时显示安全错误文本。
- 不展示托盘和主题假入口。

## 建议测试

```text
SettingsViewModel_SavesAppSettings
SettingsViewModel_RejectsInvalidRefreshInterval
SettingsViewModel_DoesNotExposeTraySettingsInMvp
MainWindowViewModel_AppliesRefreshIntervalAfterSettingsSave
```

## 不做什么

- 不编辑 Agent Options。
- 不发送 ReloadConfig。
- 不做托盘。
- 不做主题系统。
