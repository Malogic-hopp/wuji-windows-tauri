## status refresh / page refresh 解耦说明

- status refresh：独立 `_statusGate` + `_statusPollCts` + `_latestAppliedStatusSequence`，不等待页面查询
- page refresh：独立 `_pageRefreshGate`，重入时跳过并记录 `SkippedPageRefreshCount`
- status polling 不因慢页面刷新被阻塞（慢 loader 测试验证）
- status 错误不污染 page health，page 错误不污染 status health
- 采用方案 A：手动/自动 Refresh 仍先刷新 status 再刷新当前页，但两阶段 gate 完全独立
