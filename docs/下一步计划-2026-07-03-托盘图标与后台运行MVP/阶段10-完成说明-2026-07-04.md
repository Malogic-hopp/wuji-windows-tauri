## 最终托盘语义

```
CloseToTray / MinimizeToTray:
    只 Hide 窗口，不停止 status polling，不 Dispose TrayService，不 Shutdown App。
    Agent 不受影响，继续后台采集。

Exit App:
    _isExitRequested = true
    → window.Closed
    → StopStatusPolling + Dispose TrayService + Shutdown
    不默认 Stop Agent，不发送任何 Agent 命令。

Show Main Window:
    Show() + WindowState=Normal（如 Minimized）+ Activate()
    不引入复杂 Win32 强制前台 hack。

托盘状态:
    复用阶段 9 AgentStatusSnapshot / AgentCommandAvailability。
    通过 TrayMenuState.From() 推导，经 ITrayStateSink 推入 TrayService。
    不新增托盘专用状态轮询。

托盘命令:
    Start / Pause / Resume / Stop 复用现有控制服务。
    App.xaml.cs 中回调带 CanExecute 守卫，不可用时直接 return。
    TrayService 不直接依赖 AgentControlService / AgentProcessService。
```

## 状态与命令链路

```
RefreshService / status polling (2s)
    → MainWindowViewModel.ApplyStatusRefreshResult
    → latest-wins (RefreshSequence guard)
    → RefreshCommonStatus(status, processInfo)
    → AgentCommandAvailability.FromStatus(status)
    → TrayMenuState.From(status, availability, ipcSource)
    → ITrayStateSink.UpdateState(trayState)
    → TrayService.TryPostToDispatcher
    → NotifyIconTrayIconAdapter.UpdateMenuState
        → tooltip + menu item enabled 更新

托盘命令点击:
    → NotifyIconTrayIconAdapter.*Requested event
    → TrayService.TryPostToDispatcher
    → App.xaml.cs callback (CanExecute guard)
    → viewModel.*Command.Execute
    → AgentProcessService / AgentControlService (IPC-first + file fallback)
```

## 风险与遗留问题

1. **后续环境差异**：NotifyIcon 在不同 Windows 版本、高 DPI、托盘折叠设置或多显示器环境下可能有视觉差异。
2. **NotifyIcon 平台兼容**：使用 `System.Windows.Forms.NotifyIcon`，在部分 Windows 版本或高 DPI 环境下可能有视觉差异。
3. **没有正式 .ico 资源**：当前 fallback 为 `SystemIcons.Application`，不影响功能但视觉效果一般。
4. **托盘通知策略为最低实现**：MVP 只有 tooltip 更新，无 toast/balloon。如果后续需要异常通知，需新增通知机制。
