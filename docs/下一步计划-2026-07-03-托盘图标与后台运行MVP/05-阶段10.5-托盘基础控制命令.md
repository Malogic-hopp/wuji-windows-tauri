# 阶段 10.5：托盘基础控制命令 Start / Pause / Resume / Stop

## 阶段目标

让用户可以通过托盘执行 Agent 基础控制命令。

## 行为要求

```text
Start Agent:
    复用 MainWindowViewModel / AgentProcessService 现有路径。

Pause / Resume:
    复用 AgentControlService 现有路径。

Stop:
    复用 AgentProcessService Stop graceful 现有路径。

命令执行后:
    触发或等待阶段 9 status polling 更新状态。
    菜单可用性同步更新。
    错误文案安全。
```

## 控制链路约束

TrayService 不得直接：

```text
写 agent_control.json
调用 Named Pipe client
实现 IPC fallback
实现 requestId / timeout 逻辑
读写 runtime_state / health_state
```

托盘命令必须通过：

```text
现有 MainWindowViewModel command
或 TrayCommandBridge
或 AgentProcessService / AgentControlService 的现有方法
```

## 可用性约束

```text
Running:
    Pause / Stop 可用

Paused:
    Resume / Stop 可用

Maintenance:
    Start / Pause / Resume / Stop 禁用

NotRunning / Stopped:
    Start 可用

Stale + IsRunning=false:
    Start 可用

Stale + IsRunning=true:
    Stop 可用，Start 不可用
```

## 建议测试

```text
TrayCommand_StartUsesExistingStartCommand
TrayCommand_PauseUsesExistingControlService
TrayCommand_ResumeUsesExistingControlService
TrayCommand_StopUsesExistingStopPath
TrayCommand_DisabledCommandDoesNotExecute
TrayCommand_ErrorShowsSafeMessage
```

## 验收标准

```text
托盘 Start 可启动 Agent。
托盘 Pause 可暂停 Agent。
托盘 Resume 可恢复 Agent。
托盘 Stop 可停止 Agent。
IPC 正常时优先 NamedPipe。
IPC 不可用时沿用 file fallback。
Maintenance 中托盘控制项禁用。
命令失败不崩 App，不泄露路径。
MainWindow 和托盘菜单状态不漂移。
```

## 不做什么

```text
不把 PruneData / ClearHistory 放进托盘菜单。
不做 ReloadConfig 托盘入口，除非阶段 review 明确要求。
不重写 AgentControlService。
不改 IPC 协议。
```
