# 阶段 10.1：状态可见性与托盘前置整理

## 阶段目标

修复阶段 9.6 暴露的按钮禁用态视觉问题，并整理托盘接入前的状态 / 命令边界。

## 背景

阶段 9.6 手动验收中，Pause / Resume 功能正确，但禁用态视觉不明显，原因是 `SecondaryButtonStyle` 没有明显的 disabled visual state。

阶段 10 会继续强化后台运行和状态体验，因此第一步先做一个小而稳的 UI polish，避免用户误以为按钮“没反应”。

## 行为要求

```text
SecondaryButtonStyle disabled visual state 明显可见。
禁用按钮应降低 opacity 或改变 foreground/background。
Start / Pause / Resume / Stop 的可用性逻辑不变。
Settings 数据管理按钮逻辑不变。
不引入托盘图标。
不改变关闭窗口语义。
```
