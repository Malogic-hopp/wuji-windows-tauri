## 托盘命令链路

```
托盘菜单点击 → NotifyIconTrayIconAdapter.StartRequested evt
  → TrayService.TryPostToDispatcher → startAgent callback
    → CanExecute(null) guard → viewModel.StartAgentCommand.Execute(null)
      → AgentProcessService.StartAgentAsync
```

Pause/Resume 走 `AgentControlService.IPC-first + file fallback`；Stop 走 `AgentProcessService.StopAgentGracefullyAsync`。
