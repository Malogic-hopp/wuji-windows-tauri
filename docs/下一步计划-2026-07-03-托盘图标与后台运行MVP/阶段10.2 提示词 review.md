# 建议补强 1：明确 `TrayService` 不应持有 Agent 服务

你已经写了不直接执行 Agent 命令。建议再具体一句：

```text id="l6zy1x"
阶段 10.2 的 TrayService 构造函数不应接收 AgentControlService、AgentProcessService、AgentStatusService、RefreshService 或 MainWindowViewModel；只接收托盘适配器、Dispatcher/调度器、Show/Exit 回调和初始 TrayMenuState。
```

原因是 10.2 只做 Show / Exit，避免 agent 为后续功能提前注入一堆业务依赖。

---

# 建议补强 2：Exit App 在 10.2 先走现有退出语义，不要提前加 `_isExitRequested`

你已经写了 10.3 才做显式退出标记。建议补一句：

```text id="hpkzyv"
阶段 10.2 的 Exit App 可以调用现有 Application.Shutdown / 现有关闭路径；不要提前实现 CloseToTray 所需的 _isExitRequested 或 Closing 拦截逻辑。
```

这样防止 agent 把 10.3 提前做进来。

---

# 建议补强 3：Show 回调不要创造新 MainWindow

10.2 的 Show 应该恢复已有主窗口，而不是创建新窗口。建议补一句：

```text id="q2lmor"
Show Main Window 只恢复当前已存在的 MainWindow；不得创建第二个 MainWindow 或重新创建 MainWindowViewModel。
```

这能避免多窗口/多 ViewModel 造成状态漂移。

---

# 建议补强 4：`NotifyIcon.Text` 截断长度建议固定

`NotifyIcon.Text` 有长度限制，提示词已提到需要截断。建议明确一个安全上限：

```text id="2rx9ed"
NotifyIcon.Text 建议截断到 63 个字符以内，避免超过 Windows NotifyIcon tooltip 限制导致异常。
```

虽然不同平台实现细节可能不同，但 63 是常见安全值，MVP 可以先这样。

---

# 建议补强 5：测试 `Visible=false` 发生在 Dispose 前

# 建议补强 6：App.xaml.cs 接入不要影响现有 Window.Closed

这个很重要。10.2 只是加托盘图标和 Exit/Show，不改变关闭窗口。
