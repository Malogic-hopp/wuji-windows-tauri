# 阶段 10.6：托盘异常提示与状态恢复验收

## 阶段目标

补齐托盘在 Agent 断连、Stale、IPC fallback、Maintenance 等状态下的提示和恢复体验。

## 行为要求

```text
Agent NotRunning:
    tooltip 显示 NotRunning
    Start 可用

Stale:
    tooltip 显示 Stale
    根据 IsRunning 判断 Start / Stop

IPC unavailable / fallback:
    tooltip 或菜单显示简短 fallback 状态
    不泄露 full pipe name / SID / 路径

Maintenance:
    tooltip 显示 Maintenance
    控制命令禁用

恢复 Running / Paused:
    tooltip 和菜单自动恢复
```

## 通知策略

```text
第一版只做低噪声提示。
MVP 可以不弹 toast，只更新 tooltip / menu 状态。
不要对每次 2 秒轮询失败弹通知。
如果实现通知，只对状态转换通知，不对每次轮询失败通知。
可以只在关键状态转换时显示一次通知，例如 Running -> Stale、IPC connected -> fallback。
通知必须可关闭、不可刷屏。
```

## 安全展示

托盘 tooltip / menu / notification 不得显示：

```text
FullPipeName
完整 SID
本机路径
SQL
窗口标题
原始 JSON
异常原文
```

错误文本应复用现有安全短句或 `DiagnosticMessageSanitizer`。

## 建议测试

```text
TrayStatus_ShowsFallbackWithoutSensitiveDetails
TrayStatus_RecoversFromStaleToRunning
TrayStatus_DisablesDuringMaintenance
TrayNotification_DoesNotSpamRepeatedFallback
TrayNotification_UsesSafeText
TrayStatus_AllowsStartWhenStaleButProcessGone
TrayStatus_DisablesStartWhenStaleButProcessAlive
```

## 验收标准

```text
Agent 退出后托盘不崩。
Agent 重启后托盘状态恢复。
IPC fallback 安全文案可见。
Stale + process gone 可通过托盘 Start。
Maintenance 中托盘命令禁用。
通知不刷屏。
Settings dirty 不受托盘状态更新影响。
```

## 不做什么

```text
不做通知中心
不做持久化通知历史
不写 agent_events
不做真正状态流
```
