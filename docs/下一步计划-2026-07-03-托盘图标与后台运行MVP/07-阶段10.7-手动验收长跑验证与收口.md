## 手动验收

建议至少验证：

```text
1. App 启动后托盘图标出现。
2. 托盘 tooltip 显示 Agent 状态。
3. 点击窗口 X 后主窗口隐藏，App 不退出，Agent 不停止。
4. 隐藏到托盘后 status polling 继续运行，托盘状态仍更新。
5. 托盘 Show 恢复主窗口。
6. 最小化窗口后隐藏到托盘。
7. 托盘 Start Agent 可启动 Agent。
8. 托盘 Pause / Resume 可切换状态。
9. 托盘 Stop 可停止 Agent，UI 不崩。
10. Agent 停止后托盘显示 NotRunning / fallback。
11. Agent 重启后托盘显示 Running / IPC connected。
12. Maintenance 中托盘控制命令禁用。
13. Stale + IsRunning=false 时托盘 Start 可用。
14. Stale + IsRunning=true 时托盘 Start 不可用、Stop 可用。
15. Settings dirty 时托盘状态更新不覆盖编辑内容。
16. 托盘 Exit App 退出 WPF App，但不默认停止 Agent。
17. Exit App 后 Agent 进程仍按退出前状态存在，不被托盘 Exit 误停。
18. Exit App 后托盘图标不残留。
19. 运行 30 分钟，托盘状态不漂移、不刷屏、不泄露敏感信息。
20. Show Main Window 从 Minimized 恢复为 Normal 并尽力 Activate，不使用复杂前台窗口 hack。
21. Exit / Shutdown 期间点击托盘菜单不会因 Dispatcher 已 shutdown 或窗口已释放而崩溃。
```

## 风险复核

收口前需要确认：

```text
1. CloseToTray / MinimizeToTray 只 Hide，不停止 status polling。
2. Exit App 才 StopStatusPolling + Dispose TrayService + Shutdown。
3. Exit App 不默认 Stop Agent，不发送任何 Agent 命令。
4. TrayService 不直接实现 Agent 控制逻辑。
5. 托盘菜单状态来自 AgentCommandAvailability。
6. 托盘不新增状态轮询。
7. 隐藏窗口后不改变阶段 9 页面自动刷新语义。
8. Settings IsDirty 不被托盘状态更新覆盖。
9. 托盘错误展示不泄露 FullPipeName / SID / 路径。
10. NotifyIcon Dispose 幂等，不残留托盘图标。
11. NotifyIcon Dispose 前先设置 Visible=false。
12. 图标资源使用简单 fallback，不因 .ico 资产阻塞托盘生命周期。
13. Show Main Window 只做 Show + WindowState=Normal + Activate。
14. Dispatcher shutdown / window released 时托盘回调安全忽略。
```
