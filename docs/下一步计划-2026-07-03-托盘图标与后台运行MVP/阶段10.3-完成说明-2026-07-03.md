## CloseToTray 行为

- AppSettings.CloseToTray=true → 点 X 时 Cancel Closing + Hide，App 继续运行
- AppSettings.CloseToTray=false → 点 X 正常退出
- 托盘 Exit App → 设置 _isExitRequested → 允许关闭 → Shutdown

## MinimizeToTray 行为

- AppSettings.MinimizeToTray=true → 最小化时 Hide 到托盘
- AppSettings.MinimizeToTray=false → 最小化保持任务栏显示
- 退出过程中不拦截最小化

## Show Main Window

- Show → WindowState=Normal（如果 Minimized）→ Activate
- 不创建新窗口

## Exit App

- 设置 _isExitRequested → Shutdown → window.Closed → StopStatusPolling + Dispose TrayService
- 不 Stop Agent，不写 agent_control.json
